Self-authored EPUB 2 and EPUB 3 fixtures. The `.epub` archives contain the adjacent directory trees; `mimetype` is the first uncompressed ZIP entry. They include OPF metadata, EPUB 3 nav / EPUB 2 NCX, spine order, nested TOC anchors, inline bold, lists, code, SVG images, tables, MathML and long paragraphs. Unit tests inject archive extraction and read these trees; native unzip is tested by the platform/import integration.
