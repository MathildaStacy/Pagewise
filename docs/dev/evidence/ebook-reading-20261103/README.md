# 真实书籍阅读与双语排版验收

2026-11-03，分支 `codex/ebook-reading`，基于 `b81de9b`。本轮用现有书库和已有 MinerU 解析结果检查实际阅读，保留原书与精修记录；没有重新导入整本书。

## PM 评审与整改

| 读者遇到的问题 | 本轮结果 |
| --- | --- |
| 整节翻译挤在底部弹层，原文只是一个长预览，难以逐段核对 | 整节翻译进入全屏「双语阅读」。提供中英对照、中文、原文三种方式；手机上下成对，宽屏左右成对，两栏起点对齐 |
| 模型拆段或合段后，原文和译文的对应关系不可靠 | 以原文块及长块分片确定对应关系。模型增加段落不会使后续译文错位；未完成时仍可阅读原文 |
| 不同皮肤的书籍正文大小不一致，译文沿用界面文字排版 | 五套皮肤的默认书籍正文统一为 17sp、1.75 行距，正文使用书籍衬线字体；标题、图注、脚注、表格分级，跟随阅读字号设置 |
| 页面分割、逐段操作和重复分隔线打断连续阅读 | 重排正文连续呈现，页码弱化，宽屏限制行宽。精修详情在选中段落后显示；纯中文和纯原文模式使用连续书页 |
| MinerU 转义项目符号、分块编号显示成普通文字或从 1 重启 | 还原实际书中的 `\\-` 项目符号；支持印刷圆点及多种列表标记，保留非 1 起始编号。正文的下划线、波浪号转义正常显示，代码和公式内保持原样 |
| HTML 表格丢失合并关系，表头与数值容易错位 | 保留 rowspan / colspan、单元格公式及上下标；列宽按内容分配，换行后按实际内容增加行高，解决末尾文字裁切。短数据列可在手机上完整阅读，宽表可横向滚动。译文表格通过结构校验后才展示和缓存 |
| 原书小图被拉满整栏，模糊且留下大块空白 | 按图片像素尺寸、屏幕密度及实际栏宽计算等比尺寸，小图不放大，长图限制在屏幕高度的 70% 内；空图注不再占行。已用 PDF 408 页的实际小图在原生页面复查 |

参考了并行 QuantWise 阅读改进中的表格解析与段落对照方案，并适配 Pagewise 的原文块、阅读字号、皮肤和现有缓存机制。

本轮是上述章节的阅读与翻译抽检，不是整本书的逐页校对。原始解析中的缺字、错字和错序仍需原页核对及现有精修流程，例如 AIMA 20.3.2 的源文本仍有混入正文的术语；本轮没有凭排版猜测并改写原书内容。
