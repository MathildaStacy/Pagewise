# 中文扫描书与图表重绘验收

2026-11-03，分支 `codex/ebook-reading`。复用《因子投资：方法与实践》（546 页）和《打开量化投资的黑箱》（252 页）的已有 MinerU 解析结果、原始 PDF 和图片，用实际在线模型及 Android 原生页面验收。未重新上传整本书解析，未发布应用。

## 本轮改动

- 「精修本节 → 原页复核」现在包含扫描图。模型同时读取原页与已有局部图片，返回表格单元格、曲线坐标或节点连线；阅读页中的采纳结果由原生矢量组件绘制。
- 表格保留 HTML 合并关系、文字、公式和数值；只有图片的表格也可提出结构化表格建议。曲线保留坐标轴、单位、图例、日期间距、负值、对数刻度和关键标注。
- 图表随纸面主题及阅读字号显示。简单结构图按实际中文标签宽度排布，保留相对位置与双向箭头；宽图可横向滚动。图表说明默认折叠。
- 预览、采纳、缓存、原图对照和撤销沿用现有精修流程。原始内容块、图片、页码及位置不覆盖；双语阅读也复用同一重绘结果。
- 曲线明确标注「AI 近似重绘 · 数值按原图估读」。无效坐标提供一次具体反馈重试；仍无效则保留原图。模型主动指出疑点时撤回对应图片建议，包括后续批次对前图的复核。
- 实屏修复两处表格问题：字号或容器宽度变化后重新测量单元格，避免换行及末行裁切；表格预览点击直接展开，展开按钮与段落菜单不再嵌套触发。
