## 观察项与证据排除

`meta-dark-shelf-transient`、`google-dark-shelf-transient` 的首次捕获有书籍区域暂未绘出的现象；层级中存在条目，重入后正常，常态对照使用重拍后的 `*-dark-shelf`。保留原始捕获便于后续排查，不据此认定稳定的显示缺陷。

连续换肤期间捕获过一次 `LinearGradient.nativeCreate` / `BackgroundImageDrawable.draw` 前台崩溃。系统记录能确认发生过崩溃，不能确定具体 React 组件、最小序列或 release/真机是否受影响。重启后的回访未稳定复现；完整说明见 [设计报告](../VISUAL_DESIGN.md)。

字体缩放切换会重建 Activity；演示库是内存实例，切字号后重新进入演示入口再拍摄。该演示数据重置不作为真实持久书库丢数据的证据。捕获时遇到流式动画导致 `uiautomator` 无法等待空闲的情况，使用成功的新 dump 重试，未读取旧 XML。

工具准备时的 Metro 依赖目录解析问题在从同基线主工作区重启后解决，未计为产品缺陷。截图阅读使用原生图像查看；本机未发现 MinerU CLI，未为静态 UI 检查安装解析引擎或上传图片。
