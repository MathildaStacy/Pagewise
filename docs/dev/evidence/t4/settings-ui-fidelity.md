# T4 设置页双皮肤对照记录

日期：2026-10-29。范围：`MeView`、`MeMineruView`、`MeAIView`、`MeAIEditView`、`MePrefsView`、`MeStorageView`、`MeAppearanceView`、`AboutView`，以及共享 Apple `Dialog`。

## 对照依据

- 纸感：`docs/design/prototype/ui-me.js`、`docs/design/prototype/shell.html` 的 `.nav`、`.sec`、`.row`、`.fld`、`.seg`、`.sw`、`.btn`。
- 苹果风：`docs/design/prototype-apple/ui-me.js`、`base.css` 的 `.grp` / `.list` / `.row` / `.fld` / `.seg` / `.sw` / `.dlg`，`pages.css:346–364` 的外观缩略图与 About。
- 原型没有的实际功能采用相应设置分组、Sheet、Dialog 和字段样式，不另加一套视觉语言。

## 发现的差异与修改

| 区域               | 修改前差异                                       | 已完成修改                                                                                                                                                                                                                                                     |
| ------------------ | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 我的首页           | 两皮肤共用列表结构，缺少 Apple 彩色图标及大标题  | Paper 48 高导航、20 字号标题、无图标平铺分区；Apple 空白 44 高导航区后接 34 大标题，16 侧距、20 圆角分组、30×30 彩色图标、18 图形、58 起点的分隔线                                                                                                             |
| 设置分组与行       | 通用行尺寸覆盖了两套原型的差别                   | Paper 行内边距 12×14、14 正文 / 12 辅助文字；Apple 最小 50 高、11×16、17 / 13 字号；Apple 0.5 分隔线绝对定位，不额外增加行高；分组脚注放在圆角列表外                                                                                                           |
| 原型图标与颜色     | 页面直接使用 SVG / 色值，违反页面层约束          | 使用 kit 的原型路径图标与 `tokens.settingsIcons`；页面没有直接导入 skin 或 SVG 库。Paper 使用原型文字 `›`，Apple 使用 15 图标箭头                                                                                                                              |
| 解析服务           | Token 编辑、额度、模型等拆成了不同布局           | 主组恢复原型顺序：只读 Token、有效期 + 更新按钮、额度 + 进度、150 宽模型选择、上传开关、测试连接；只读 Token 保持正文颜色，自建服务字段保持禁用颜色                                                                                                            |
| AI 服务            | 模型分配与用量未分皮肤布局                       | Paper 保留边框 select 字段、分组内 Note 和 kv 用量；Apple 使用行内标题 / 辅助文字 / tint 模型选择及 updown 图标、分组外脚注、独立用量行                                                                                                                        |
| AI 编辑            | 两套保存操作位置相同                             | Paper 保持测试 / 保存并排；Apple 保存位于导航栏右侧，读取模型与测试连接为操作行。返回标签为 AI 服务                                                                                                                                                            |
| 讲解偏好           | 讲解长度被拆出原型分组、开关顺序不一致           | 恢复直觉、长度、结尾问题、小测、双语、续学回顾顺序；长度控件 Paper 130 宽 / Apple 120 宽；补充要求按原型第二分组展示                                                                                                                                           |
| 存储               | 清理采用 Sheet，书与备份操作顺序不一致           | 每书右侧紧凑清理按钮；清理改用 Dialog；备份恢复保持原型顺序。重新解析与备份原文件等实际新增功能继续使用通用设置 / Sheet                                                                                                                                        |
| 外观               | 只有按钮式皮肤切换，没有原型缩略图               | 双列皮肤缩略图、选中边框、深浅色勾选行、字号分段与一条正文样例。缩略图通过嵌套 `SkinProvider` 获得对应色板，Paper 缩略图保持固定浅色；Apple 缩略图随当前深浅色                                                                                                 |
| About              | 两套内容布局近似，开发操作占据原型正常态         | Paper 保留单白色块、22 品牌文字与隐私 Note；Apple 恢复 84 图标 / 24 品牌文字 / 隐私组 / 版本与协议行。开发工具收在长按版本入口；演示态在 release 也可直接退出                                                                                                  |
| 可见按钮与触摸范围 | 通用 48 高按钮改变原型尺寸                       | Paper 42 / small 30，Apple 50 / small 34；通过 hitSlop 增大触摸范围。Apple 按压 scale .97，并遵守 reduceMotion                                                                                                                                                 |
| Apple 确认弹窗     | 360 宽、24 圆角、通用 gap、48 高动作，不同于原型 | 300 最大宽、40 侧距、28 圆角；标题 padding 20/18/2、17×1.3；正文 padding 6/18/18、13×1.55；46 高横排操作、0.5 分隔线；`danger` 红色确认。保留强玻璃 30 blur，使用原型外阴影和内边线；缩放 1.12→1（320ms）、正文淡入 200ms、遮罩 300ms，reduceMotion 时立即完成 |

业务值（真实书名、Token 状态、服务模型、额度和用量）取 VM 数据。当前 MinerU 官方额度为 1000 页，不伪造纸感旧静态原型中的 2000 页。Token 的真实编辑放在“更新 Token”Sheet 中，继续使用 KeyStore；鉴权、模型读取、备份原文件、重新解析等原型未展示的实际功能仍保留。
