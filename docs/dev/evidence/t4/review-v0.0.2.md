# v0.0.2 系统检查（阶段结果）

检查基线：6988520 / v0.0.2，2026-10-29。用户要求先审查到这里；以下是已经确认的结果，不是完整验收。未改产品代码。

## 功能和大字号

1. **Apple 复习卡答案被遮挡（P1，原生复现）**：模拟器系统字体 2.0，Demo → 苹果风 → 复习 → 开始复习 → 翻开第一张卡，答案最后一行被「回到原文 / 问 AI」遮住；在卡片上向上滑动后仍被遮住。见 [答案](v0.0.2-system-review/apple-card-answer-font2.png) 和 [滑动后](v0.0.2-system-review/apple-card-after-swipe-font2.png)。`src/ui/screens/ReviewSessionView.tsx` 的翻转卡容器固定高 380，正反两面绝对定位。实际 TalkBack 听读未测试，UI 树保留完整答案文字。
2. **复习盒子的间隔被截断（P2，原生复现）**：同一条件下复习概览的五列显示「盒 1 · …」等省略号，天数不可见；见 [截图](v0.0.2-system-review/apple-review-font2.png)。`ReviewView.tsx` 将每列标签固定单行，而 presenter 提供的是「盒 n · x 天」。
3. **封面文字在 2 倍字号下被裁切（P2，原生复现）**：Paper Demo 书架的中文封面仅显示部分文字且底部字被切断；Apple 书架也观察到。见 [Paper 截图](v0.0.2-system-review/paper-shelf-font2.png)。书名在封面旁的书籍列表仍可读；问题限于固定尺寸封面中的文字。`controls.tsx` 的封面尺寸固定，文本仍跟随系统字号放大。

## 与原型的已确认差异

4. **Paper 段落菜单仍是两行（P2，原生复现 + 原型源码核对）**：普通字号点击重排图片后，第一行五项，第二行「笔记」独占整行；见 [截图](v0.0.2-system-review/paper-figure-menu.png)。Paper 原型 `prototype.html:267–269` 是单行 flex，`selBlock` 提供五项；当前另外有「从这里开始讲」且允许换行。此处记录布局与原型差异，不把产品是否应保留额外动作作为既定结论。
5. **Apple 重排图片仍有边框和固定高度（P2，原生复现 + 原型源码核对）**：见 [截图](v0.0.2-system-review/apple-figure-menu.png)。原型 `prototype-apple.html:509` 的阅读图片背景透明、上下内边距 4；通用原型 `.fig` 无边框。当前 `content.tsx:1503` 仍绘制 1px 边框、8 内边距，并把图片固定在 180 高；原型图像宽度自适应、高度按内容。这是样式差异，不能仅据此推断所有图片失真。
6. **Apple 封面修复不完整（P2，源码核对）**：普通封面现在是 54×74、白字，但大封面仍为约 84×115（`controls.tsx:1060–1071`），原型 `.cover.lg` 为 62×84；大封面用于导入设置和解析进度。原型的整面渐变光泽也仅被当前左侧窄色块近似，未实现完整渐变。具体页面最终模拟器逐项尺寸未复测。
7. **Apple 段落菜单视觉高度仍不同（P3，原生复现 + 原型源码核对）**：单行和横向滚动已经生效，但当前按钮最小高度 48dp，原型视觉高度 40px；见 [截图](v0.0.2-system-review/apple-figure-menu.png)。修复时仍需保留至少 48dp 的触控目标。

## 已复验的通过范围

- Paper 和 Apple 的 Demo 重排图片点击均显示段落菜单，不再无响应。
- Apple 原生无障碍树中，多个段落名称包含实际正文及当前 / 已讲状态；不等于完成 TalkBack 语音流程。
- Apple 普通字号菜单为单行；系统 2 倍字号下可向右横向滚动至「笔记」。Paper 地图的学习中状态显示半填充圆。
- Apple 系统 2 倍字号下复习卡正面、翻面和评分按钮出现；答案内容遮挡见问题 1。
