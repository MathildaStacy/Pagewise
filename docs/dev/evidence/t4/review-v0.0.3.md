# v0.0.3 修复与验证

2026-10-29，修复 [v0.0.2 阶段报告](review-v0.0.2.md) 中的 7 项问题。

## 本次修复

1. Apple 复习卡由当前可见的一面决定高度，另一面仅参与翻转动画。答案不再压缩到固定的 380dp 内，操作按钮跟在答案后面，评分按钮也可随字号增高。
2. 两套复习概览的盒子标签允许换行，完整显示盒号和间隔天数。
3. 封面文字在固定画幅内自动适配字号，保留完整的封面无障碍名称和旁边随系统字号放大的书名。
4. Paper 段落菜单改为单行横向滚动，保留现有六个操作。
5. Apple 重排图片的容器透明、无边框、上下内边距 4dp；图片根据加载成功后的原始尺寸计算高度。切换图片时重建图片组件，过期加载事件不改变新图片的比例。
6. Apple 大封面为 62×84dp。整面光泽使用现有 SVG 依赖绘制渐变，SVG 使用与封面相同的数值尺寸，避免百分比尺寸受到内边距影响。
7. Apple 段落菜单的背景与按钮视觉高度为 40dp，触控区域至少 48dp；大字号时内容可以增高，操作保持单行滚动。

## 验证

- `npm run check`：lint、TypeScript 和 80 个 Jest 测试套件通过，1199 tests、15 snapshots。
- Android arm64 release 构建通过；版本号 0.0.3，versionCode 3。
- 新增图片比例及过期加载事件、三种封面光泽尺寸回归测试，更新复习卡自适应布局和菜单单行滚动验证。
- Pixel_10_Pro / Android 17，1280×2856、density 480，使用内存隔离 Demo 检查 UI。部分后续截图由临时 Demo 启动入口采集；入口已恢复，未纳入产品改动或 release 构建。
- Apple 2 倍字号首张答案完整显示：答案底部 y=1326，操作按钮顶部 y=1368，相隔 14dp；评分文字完整显示。
- Apple 2 倍字号复习盒的五组间隔完整可读。
- Paper 浅色、深色 2 倍字号封面文字未裁切。
- Paper 浅色、深色段落菜单的六个操作同处一行，触控区域高度均为 48dp。
- 原生图片显示比例与 960×450 的 Demo PNG 一致：显示区域约 1049×492px。
- Apple 大封面原生测量为 186×252px，即 62×84dp；最终渐变覆盖范围另有三个尺寸的自动化回归测试。

截图和 UI 树位于 [v0.0.3-fixes](v0.0.3-fixes/)。系统字号已恢复为 1.0。
