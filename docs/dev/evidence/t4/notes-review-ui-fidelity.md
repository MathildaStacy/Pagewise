# Review / Notes 双皮肤原型收敛

日期：2026-10-29。范围：`ReviewView`、`ReviewSessionView`、`NotesView`、`NotesBookView`、`NoteDetailView` 及笔记导出预览 presenter。原型没有修改。

## 对照依据

- 纸感：`docs/design/prototype.html`，对应源文件 `prototype/ui-review.js`、`prototype/shell.html` §复习/笔记样式。
- 苹果风：`docs/design/prototype-apple.html`，对应源文件 `prototype-apple/ui-review.js`、`prototype-apple/pages.css:285` 起和 `base.css` 的分组、编辑器、浮层规则。
- 原型中的书名、计数、章节、问答内容是演示数据。正式页面继续使用 VM 的真实数据，交互继续调用原有 usecase。
- 页面读取 kit 的语义展示契约 `usePresentation()` / `tokens.layout`；没有读取 skin ID，没有在页面导入数据、平台或服务层。

## 保留的真实交互

- 翻卡、忘了/模糊/记得、复习完成、回到原文和问 AI 均调用原来的 intents；未增加本地演示行为。
- 评分前必须翻面、重复评分锁、Leitner 更新和卡点生成仍由 VM/usecase 执行。
- 翻面后隐藏正面的无障碍树；翻面前隐藏背面和操作，避免读到答案。Reduce Motion 时立即切面。
- 笔记高亮与苹果问答便签继续跳转真实来源；个人笔记继续自动保存。
- 导出按钮继续执行真实 Markdown ZIP / Anki CSV 导出。浮层副标题包含真实笔记小节数。
- 错误、加载、空内容与长内容状态保留。未使用强制 48px 可见按钮尺寸；小按钮尺寸由共享 kit 决定。
