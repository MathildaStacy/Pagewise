## 原生流程

任务专属 Pixel 10 Pro 模拟器，Android API 37.2、1280 × 2856，约 426 dp 宽。使用本地合成的两页 PDF；标题层级、断词、公式、表格和代码都有独立样本。服务名明确为「本机验收服务」，请求发送到本机 HTTP 模拟服务，使用虚拟凭据。

1. 结构精修生成两批建议，检查断词和标题层级，逐项选择并采纳。
2. 原页复核实际运行 PDF 页面渲染、临时图片编码、AI 网关请求和结果保存，生成公式 / 表格修复建议。
3. 采纳后重排阅读立即更新，显示「AI 精修」标记；保留页码定位与代码阅读操作。
4. 撤销恢复解析原文，修订建议仍可重新审阅。
5. 深色、系统字号 1.3 下检查对照、滚动和采纳操作。取消表格建议，查看原文、关闭原文弹层后重新打开精修，仍显示未勾选和「采纳 3 处修改」。
6. 疑点可查看解析原文并打开原版 PDF 书页。结束后恢复模拟器字号与深浅色设置。

这些检查验证交互、数据和请求链路，尚未评价真实在线模型的 OCR、公式和表格识别准确率，也未验证实体 Android 设备上的手势体验。
