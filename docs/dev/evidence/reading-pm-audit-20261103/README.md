# 书页、翻译与 AI 讲解的 10 项体验优化

2026-11-03，Pagewise，`codex/ebook-reading`，基于 `b88fc0e`（v0.0.20）。

## 问题与改动

| # | 体验问题 | 已完成的优化 |
| --- | --- | --- |
| 1 | 书页工具分散，精修等低频操作挤占阅读空间 | 常驻「翻译本节」「阅读设置」，本节对话与精修收进「阅读工具」；两个书页入口共用组件。 |
| 2 | 调字号、切深浅色需要离开书页 | 增加页内设置，原文和双语阅读均可打开；设置同时作用于原文、译文与 AI 讲解，并保存到本地。 |
| 3 | 双语阅读方式与翻译进度随正文滚走 | 将模式、进度、设置和模型入口固定在顶部，正文使用独立列表滚动。 |
| 4 | 中英模式切换后容易偏离正在读的段落 | 以原文块为锚点，等待新布局测量后恢复该段；清理定位帧和重试计时器。保留的是段落，不保证同一行或同一像素。 |
| 5 | 原文与中文主要靠竖线区分，未译状态含糊 | 对照模式明确标注「原文」「中文译文」；中文模式的未译内容保留原文，并显示未译提示。公式、图片等保留块不重复翻译。 |
| 6 | 查看出处会替换译文，回来丢失阅读状态 | 出处作为第二层打开，译文页面继续保留；返回后维持中文／原文／对照模式及位置，正在进行的翻译也不被取消。 |
| 7 | 讲解的状态与重试入口不够一致 | 实际讲解入口接入统一正文，分别显示「AI 讲解」「正在讲解」「讲解完成」「讲解中断」；支持停止、重新讲解和失败重试，原文可展开核对。 |
| 8 | 翻看长对话后难以回到最新回复 | 离开底部时出现「回到最新讲解」，显式点击可返回最新内容；翻看旧内容时暂停跟随。 |
| 9 | 长回复难以选择和完整复制 | 讲解完成后支持文本选择，并提供「复制讲解」及成功／失败反馈；复制保留公式、引用及列表编号。 |
| 10 | 宽屏讲解行宽过长 | 对话正文居中且最大宽度为 800dp；宽屏双语阅读仍按原文块左右对应。 |

## 原生验收

使用本任务独占的 Pixel 10 Pro 只读模拟器（`emulator-5582`）。手机为 1280 × 2856、480dpi，横屏为 2856 × 1280；宽屏分别为 2560 × 2856 和 3600 × 2856。覆盖系统字号 1.0 / 1.3、应用大号阅读字体，以及浅色／深色；系统大字号另经冷启动复查。

- *Machine Learning for Trading* 的 10.3 Sequential models：从已有完整翻译缓存进入；核对 RNN / LSTM 段落在中文、原文和对照模式间的定位；查看 p.233 后返回同一段中文。系统大字号下，模式切换与阅读设置保持可用。
- 同书 The frictions faced by liquidity providers 的真实 22 条消息对话：上翻出现「回到最新讲解」，点击返回；整条复制显示成功反馈；1200dp 宽屏的正文保持居中行宽。
- 实际段落菜单的「解释」入口：确认新讲解布局已接入。该次请求未连上现有 AI 服务，界面正确显示「讲解中断」「重试讲解」及服务设置入口；本轮未取得新的在线讲解完成结果。完成、生成中、停止和失败状态另由实际页面入口的自动回归覆盖。
- 最终 arm64 Release 已覆盖安装到上述独立模拟器，保留书库与对话，并验证已有长对话、复制、滚动和页内设置。当前测试窗口内未记录到应用进程的 ReactNativeJS / AndroidRuntime 错误。

验收脚本在开发重载时曾复用已经关闭的数据库连接，导致一次书架错误；已修正本地临时脚本。正常启动及最终 Release 的外观切换未复现该错误。临时脚本与完整 UI 层级文件保留在忽略目录 `fixtures/private/pm-audit-20261103/`。
