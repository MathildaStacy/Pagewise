# AI 文档精修

## 目标与成功标准

在已导入书籍的当前小节上修复排版与识别错误，让重排阅读、伴读和英文翻译共同受益。用户先看修改，再采纳；始终能回到原 PDF 核对，也能撤销。导入完成即可阅读，精修不阻塞解析。

第一版包含结构精修及可选原页复核两个模式。结构精修修复换行、断词、标题层级和跨页续段；不凭上下文补写原书。原页复核将当前块所在 PDF 页面发送给支持图片输入的模型，校正 OCR、公式与表格。代码和图片资源不重写。不引入服务端。

采用「解析原文 + 可撤销修订 + 阅读投影」：直接覆盖解析结果会破坏原文核对和高亮定位；整本重生成又难以审阅、续跑和控制调用成本。当前小节的分批修订能沿用已有导入、阅读和 AI 网关，并把是否采纳留给读者。无法由原页确认的内容列为疑点。

## 方案

- `block` 始终保存解析原文；新增 `document_refinement` 保存小节快照、分批进度、模型配置、修改建议、疑点和采纳状态。
- 模型返回结构化修改，目标必须是本批源块。原块 `seq/page/bbox` 不变；跨页续段用 `continuesFrom` 表达，保留每块的独立定位。标题只修正阅读层级，不自动重建用户的章节树。
- 普通精修强制保留原文字符（允许空白、软连字符和行尾断词变化）。需要改字、公式或表格时提示原页复核。原页模式仅在 PDF 原件存在且模型明确支持图片输入时开放；每批最多两页。
- 一次只处理当前小节；长小节按块分批，上下相邻块作为只读上下文。每批结果提交 SQLite 后才推进进度。取消/离开页面后保留已完成批次；重开可继续，不重复调用已完成批次。
- 模型、推理强度复用整理模型与现有模型选项；精修禁用联网与工具，文档内容作为待处理数据。生成建议本身不修改阅读内容。
- 逐项选择并采纳，或者撤销整个修订；只有采纳的建议进入阅读投影。原版 PDF、原文定位与高亮偏移仍基于原始块。原文对照显示未修订文本。
- 伴读上下文和翻译使用同一阅读投影，标明 AI 修订，历史消息不重写。已打开的会话在下一次请求前刷新源块；已有翻译通过 `source_text` 比对自然失效。
- 重新解析/清理派生数据使受影响修订失效；修改前后均校验快照，防止在新原文上应用旧建议。备份使用现有 SQLite 快照，修订随书保留，删除书籍级联删除。

## 交互

读书工具条提供「精修本节」，听讲模式菜单也能打开。复用当前皮肤的 Sheet、按钮、进度与提示样式。面板展示范围、模式、AI 服务、处理进度、疑点、逐块前后对照，以及开始/停止/继续/采纳/撤销操作。生成中可关闭并取消网络调用。已采纳块标记「AI 精修」，可查看解析原文。
