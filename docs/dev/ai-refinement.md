# AI 文档精修

## 目标与成功标准

在已导入书籍的当前小节上修复排版与识别错误，让重排阅读、伴读和英文翻译共同受益。用户先看修改，再采纳；始终能回到原 PDF 核对，也能撤销。导入完成即可阅读，精修不阻塞解析。

第一版包含结构精修及可选原页复核两个模式。结构精修修复换行、断词、标题层级和跨页续段；不凭上下文补写原书。原页复核将当前块所在 PDF 页面发送给支持图片输入的模型，校正 OCR、公式与表格。代码和图片资源不重写。不引入服务端。

采用「解析原文 + 可撤销修订 + 阅读投影」：直接覆盖解析结果会破坏原文核对和高亮定位；整本重生成又难以审阅、续跑和控制调用成本。当前小节的分批修订能沿用已有导入、阅读和 AI 网关，并把是否采纳留给读者。无法由原页确认的内容列为疑点。

## 方案

- `block` 始终保存解析原文；新增 `document_refinement` 保存小节快照、分批进度、模型配置、修改建议、疑点和采纳状态。
- 模型返回结构化修改，目标必须是本批源块。原块 `seq/page/bbox` 不变；跨页续段用 `continuesFrom` 表达，保留每块的独立定位。标题只修正阅读层级，不自动重建用户的章节树。
- 普通精修强制保留原文字符（允许空白、软连字符和行尾断词变化）。需要改字、公式或表格时提示原页复核。原页模式仅在 PDF 原件存在且模型明确支持图片输入时开放；每批最多两页。
- 一次只处理当前小节；长小节按块分批，上下相邻块作为只读上下文。每批结果提交 SQLite 后才推进进度。取消/离开页面后保留已完成批次；重开可继续，不重复调用已完成批次。
- 模型、推理强度复用整理模型与现有模型选项；精修禁用联网与工具，文档内容作为待处理数据。生成建议本身不修改阅读内容。
- 逐项选择并采纳，或者撤销整个修订；只有采纳的建议进入阅读投影。原版 PDF、原文定位与高亮偏移仍基于原始块。原文对照显示未修订文本。
- 伴读上下文和翻译使用同一阅读投影，标明 AI 修订，历史消息不重写。已打开的会话在下一次请求前刷新源块；已有翻译通过 `source_text` 比对自然失效。
- 重新解析/清理派生数据使受影响修订失效；修改前后均校验快照，防止在新原文上应用旧建议。备份使用现有 SQLite 快照，修订随书保留，删除书籍级联删除。

## 交互

读书工具条提供「精修本节」，听讲模式菜单也能打开。复用当前皮肤的 Sheet、按钮、进度与提示样式。面板展示范围、模式、AI 服务、处理进度、疑点、逐块前后对照，以及开始/停止/继续/采纳/撤销操作。生成中可关闭并取消网络调用。已采纳块标记「AI 精修」，可查看解析原文。

## 结构精修 v2：标题与正文切分

### 问题（真机 AIMA 第 21 章复现）

- **整批失败**：`parseRefinement` 遇到任何一行不合规（例如在正文块上多给了 `latex` 字段、续段指向非相邻块、疑点指向上下文块）就抛错，整批作废、整次精修停在「x / 10 批」。重试只会以同样概率再次失败。
- **能做的事太少**：一条修改只能改一块的文字、`text↔title` 和层级。原书常见的结构问题都表达不了：页边术语（AIMA 的 *Unit*、*Layer* 等缩进斜体词）被解析成标题；粗体起头的段内小标题粘在正文里；「Chapter 21」与「Deep Learning」被拆成两个标题；跨页段落被页码切断。
- **改了也看不出**：`continuesFrom` 只改按钮文字，阅读时段落仍被切开；未精修标题不区分层级，MinerU 又几乎把全部小节标题压成同一级（ML4T 夹具 347 个标题中 339 个为 level 2）。

### 方案

- **规则先行，零调用也有效**：确定性规则直接给出建议，AI 只补规则判断不了的部分。
  - 编号推层级：`Chapter 21`/`第 21 章` → 1，`21.1` → 2，`21.1.1` → 3；同节内无编号标题接在编号标题后降一级。
  - 页边术语：比正文左缘明显右缩、很短、无句末标点、且在相邻正文里出现的块标为「旁注」。
  - 续段：上一正文块无句末标点、下一块以小写或中文续写，且中间隔着换页或图片/图注/脚注时，标为接续。
  - 标题标签与标题名相邻（`Chapter 21` + `Deep Learning`）时合并显示。
- **按角色而非改写**：结构模式的 AI 输出改为 `role`：`heading`（含 `level`）、`body`、`runin`（`heading` 给出段首小标题原文）、`note`、`continue`。AI 不必复述正文，`runin` 的小标题必须是原文前缀，因此结构模式不可能改字。
- **逐行容错**：单行不合规只降级为该块的疑点并保留原文；本批以外的块、重复块、正文上的多余公式字段被忽略并记录；只有整段输出不是 JSON 时整批失败，且自动重试一次。
- **阅读投影 1:1 不变**：每个源块仍对应一个阅读块，`seq`、页码、高亮、伴读与翻译都不受影响。切分只体现在 `refinement.heading`（段首小标题字符数与层级）和 `refinement.role`；续段在重排视图中把文字接进上一段，被接入的块仍可被定位、高亮。
- 标题层级在重排视图中始终生效（不再仅限已精修块），1 级为章标题，3 级及以下为小节标题。

### 章节地图与阅读修正

- 地图与精修共用版面识别：按位置和相邻正文识别页边术语，过滤目录页行、图表标签和误识别成标题的长句。电子书链接图标不再干扰目录页码和句末标点判断。
- 合并分开的章节编号与名称，识别 `A.1` 等附录编号；无编号小标题归到最近的编号小节，章末小结和参考说明归到章下。PDF 书签足够详细时，用书签约束额外的小标题切分。
- 较长的章首、节首正文单独形成「本章导读」「本节导读」；较短的引言随首个小节保留，包括父级标题。长小节拆段不再计入「需要确认」。
- 同页相邻算法行不自动续接。结构模式的 AI 续段也必须满足上一段未结束、下一段呈续写形态；原页复核保留按页面判断的能力。
- 重排、建议对照和翻译统一移除 MinerU 独立公式外层的 `$$` / `\[ \]`，公式编号随公式显示，避免 MathJax 的页面宽度布局挤压公式。
- 阅读中的链接图标不显示；仅文字发生可见变化的块显示「AI 精修」。结构建议通过标题、旁注及续段本身体现。
- 公式先显示 TeX 占位；WebView 冷启动与单公式渲染分别限时 15s / 3s。当前公式的迟到结果仍可更新界面，避免慢启动后长期停留在 TeX。
- 展开 MathJax 拉伸括号使用的等比例嵌套 SVG 视口，保留原剪裁区域，修复 Android 长矩阵括号中段缺失；已有公式缓存读取时一并修正。
- 原页复核的修改幅度按去掉 `sub` / `sup` 标签后的文字长度衡量，避免 MinerU 将普通字母错误包成下标时，正确的去标签校对被误判为大段删字。结构模式仍保持原文字符不变。
