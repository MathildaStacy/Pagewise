# v0.0.17 阅读渲染修复

2026-11-02，针对 [v0.0.16 皮肤与文字渲染审查](skin-reading-audit-v0.0.16.md) 中已复现的问题。修复在显示层即时生效，已有书籍无需重新导入；没有改写原始 OCR 内容或学习记录。

## 改动

- **公式兼容性**：使用本地 MathJax 完整 SVG 资源，显式启用所需扩展；支持 `boldsymbol`、`dag`、`hdots` 及书籍中使用的文本／字体命令。仍离线工作，不使用 CDN 或自动网络加载。`textsc` 使用直立字形保留字符，SVG 数学字体不具备真正的小型大写字体。
- **上下标**：正文中的 HTML `sup`／`sub` 转为保留内容的上标／下标；代码片段和已有 TeX 不作同样处理，不修改源内容的负号或变量。
- **表格**：阅读预览、展开表格、精修表格对照共用富文本单元格，公式与上下标能实际排版。预览展示前两列、最多三行，完整表格保留全部列。
- **横滑**：表格与长公式使用原生手势协调的横向滚动，公式 SVG 不再截获触摸；支持直接在内容上拖动，避免误触段落菜单。
- **苹果风**：关闭模糊时使用不透明材质回退，避免弹层透出底层正文；浅色辅助文本在白底对比度从 3.62:1 提高到 5.45:1，在浅色页面背景上约 4.88:1。
