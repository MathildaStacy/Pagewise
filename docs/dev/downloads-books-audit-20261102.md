修复后共 **21,908 个内容块**。全量自动检查确认每个块恰好落入一个可阅读叶子单元，无重复归属、无遗漏归属。适配器逐项保留真实结果中的非空 `ref_text`、`page_footnote`、`aside_text`，并继续排除重复页眉页码。

8 页原页保留有明确依据：MinerU 检测出了文本/表格区域却没有返回可用内容，或把脚注续行当成唯一页眉。App 使用本机原 PDF 渲染图像并标明“此页文字未能识别，已保留原页图像”。这些图像不等于成功 OCR，不支持按其内部文字选段、检索或直接生成文字引用。空白插页的全画布空文本占位不生成假正文。

其他目录修复包括：独立书签标题不再被相邻标题拼接；章节与其小节按 Part 深度排列，超过地图三级的标题保留在阅读正文；短的版权/前言不会再被并入正文学习单元。数字章节书签仅在大量条目满足同一页码偏移及密集分布时才判为逐页导航，小型数字章节目录仍保留。

全量是指完整云端解析、全部结果适配及结构/归属检查。人工阅读和原页图像核对为针对性抽查，没有声称逐字校对全部 2,879 页。源文件、原始结果、逐块导出和原页证据保存在被 Git 忽略的 `fixtures/private/downloads-20261102/`。
