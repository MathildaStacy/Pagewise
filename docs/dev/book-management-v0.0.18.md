# v0.0.18 书籍管理与导入错误修复

2026-11-02。解决旧版本解析不佳后无法从书架删除、重复导入只会打开旧书的问题，并修复导入失败时暴露原生英文错误和冗长文件路径的提示。

## 使用方式

- 书架列表和网格中的每本书都有「…」管理按钮，也支持长按书籍。
- 「重新解析」复用本机原文件，重新生成正文和目录，保留学习记录、笔记、闪卡和手动修改的目录。PDF 开始前说明会重新上传到 MinerU、消耗解析额度；默认启用 OCR，可手动关闭。EPUB 在本机解析。
- 「删除书籍」先展示确认页，明确说明会删除 App 内该书的原文件、解析结果和学习数据，无法撤销；Downloads 中的原书不受影响。确认后可再次导入同一文件。
- 从书架选取重复文件，或从其他 App 分享重复文件，都打开同一个管理面板，不再直接跳到旧目录。
- 原文件已丢失时，重新选择同一本书可以补回文件；缺少 MinerU Token 时先引导设置解析服务。

## 实现要点

导入、重新解析和删除使用同一串行入口。删除先停止并等待正在运行的解析、精修和学习任务，再在事务中移除该书数据、关联设置与同哈希草稿，最后清理 App 私有文件和缓存。数据库删除失败时保留原文件；文件清理不完整时明确提示，但已删除的哈希不会继续阻止重新导入。其他书籍的解析队列随后恢复。

导入错误统一映射为短中文操作建议，覆盖文件名过长、文件不存在、权限不足、空间不足、密码保护和不可读取文件。选择文件期间显示读取状态，错误留在导入面板中；不会展示原生错误中的完整路径。应用自行生成的有效输入提示继续保留。

## 验证

`npm run check` 通过 ESLint、TypeScript、**119 个测试套件、2,138 项测试和 15 个快照**。覆盖删除后相同哈希重新导入、关联数据清理、正在上传时删除、事务失败保留原文件、清理失败提示、OCR 参数替换与记录保留、重复操作防护、取消确认、外部分享导航隔离、长中文文件名与路径脱敏。

Android arm64 Release 构建通过；在专用模拟器 `emulator-5590`（1280 × 2856 px、density 480）覆盖升级，签名与 v0.0.17 一致，不依赖 Metro。
