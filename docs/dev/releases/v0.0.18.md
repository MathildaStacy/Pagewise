# Pagewise v0.0.18

Android Preview：支持删除书籍和直接重新解析，解决旧书重复导入被挡住的问题，并简化导入失败提示。

- 书架每本书新增「…」管理菜单，也支持长按，可打开、重新解析或删除。
- 重复上传同一本书时提供管理选项；从其他 App 分享文件也支持。
- 重新解析保留学习记录、笔记、闪卡和手动目录。PDF 默认开启 OCR，开始前说明上传与额度；EPUB 在本机解析。
- 删除前确认会清除该书在 App 内的原文件、解析结果和学习数据，Downloads 原书保留；删除后可以重新导入同一文件。
- 导入错误改为简短中文建议，不再展示冗长路径和原生英文异常。

验证：ESLint、TypeScript、119 个测试套件、2,138 项测试、15 个快照通过；Android arm64 Release 构建、覆盖升级、合成 EPUB 导入／重解析／删除／重新导入、系统分享重复文件和五套皮肤面板检查通过。详见 [修复与验收记录](../book-management-v0.0.18.md)。本次未重新执行六本真实 PDF 的云端 OCR。

安装包：`Pagewise-v0.0.18-android-arm64.apk`，versionCode 18 / versionName 0.0.18，最低 Android 7.0（API 24）。沿用与 v0.0.17 相同的 Android Preview 开发签名，支持覆盖安装；附 `SHA256SUMS`，标记为 prerelease。
