# Pagewise v0.0.9

Android 预览版，新增当前小节的可选 AI 文档精修。导入后即可阅读，需要时再精修，先对照、后采纳。

- 结构精修处理换行、行尾断词、阅读标题层级与相邻续段；代码和图片保持原样，需要改字的问题列为疑点。
- 原页复核将对应 PDF 页面发送给支持图片输入的模型，核对 OCR、公式和表格；界面明确说明图片发送范围，并以可读的公式和表格展示前后对照。
- 建议可逐项选择、采纳和整次撤销。查看原文再返回后保留当前选择；原始 PDF、解析块、页码定位、高亮和历史对话保留。
- 重排阅读、后续 AI 伴读及翻译使用同一份已采纳内容，旧译文根据原文变化失效；长小节分批保存进度，支持停止后续跑。
- 重新解析或清理派生缓存时使旧建议失效；精修记录随现有 SQLite 备份保存和恢复。

包含 main 的 v0.0.8 改动，兼容章节多对话、模型 / 推理 / 搜索选项、整节翻译、键盘避让、五套皮肤及 IDE 风格代码阅读。

精修交互及图片请求链路已通过本地模拟服务验证，尚未评价真实在线模型的 OCR、公式和表格识别准确率。

ESLint、TypeScript、103 个测试套件、1972 项测试和 15 个快照通过；保留 1 套、2 项依赖未提供的私有 MinerU fixture 的测试跳过。Android arm64 Release 构建通过，安装包版本、架构与签名校验通过。

安装包为 `Pagewise-v0.0.9-android-arm64.apk`，最低 Android 7.0（API 24），versionCode 9，无需 Metro。沿用 Android Preview 开发签名；已从正式发布的 v0.0.8 覆盖升级，原有两本书、可见对话和学习进度保持一致，离线冷启动无运行时错误。附 `SHA256SUMS`。本版仍为 prerelease。

详细方案及验收：[AI 文档精修](../ai-refinement.md)、[原生验收记录](../evidence/ai-refinement/README.md)。
