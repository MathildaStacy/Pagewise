# Pagewise v0.0.25

Android Preview：伴读能按段读原文、翻目录、做计算；多轮对话的请求前缀更稳定，更多命中提示词缓存；修复模型开岔路后回主线、之后每次提问都报错的问题。

- 修复：模型自己读一节原文（load_section）开出岔路后，点「回主线」，之后在 OpenAI Responses 与 Anthropic Messages 协议下每次提问都报 "No tool output found for function call"。原因是读原文的调用留在主线、结果随岔路收起；现在两者一起收起，发请求前也会去掉配不上对的调用或结果，旧版本存下的这类对话打开后同样能继续。
- 伴读新增三个工具：按段落编号读完整原文（一次 1–12 段，读到的段落之后几轮仍可引用）；分页查看小节目录（每页 50 个，可限定某章之下）；计算器（加减乘除、乘方与括号），可对多个算式排序、取最大最小值并标出并列。目录和计算结果不能当作原文引用。
- 提示词缓存：每轮变化的学习记录移到请求末尾，之前的对话保持为可复用的前缀；Anthropic 对话把剩下的一个缓存断点放在学习记录之前。岔路里读到的原文留在读它的那段对话里，进出岔路不再打乱前面的历史。Chat Completions 协议只对官方 OpenAI 发送 prompt_cache_key，DeepSeek、智谱与自定义服务不发，避免不认识字段的服务报错。
- 模型既没回答也没调用工具时，提示「AI 未返回内容，请重试」，不再留下空白回答。引用写成 `[[b123]]`（漏了冒号）也按同样规则核对来源。中转服务在出字前返回 502/503/504 时，改用流式重试一次。
- 按「停止」后，排队中的工具调用不再执行，也不会再打开岔路；已保存的调用仍配有结果，下一轮请求不会出错。
- 笔记书架用一次查询统计各书的小节笔记、问答与批注；书的笔记页批量读取个人笔记与划线段落，单节详情只读该节。

包含 v0.0.24 的中文原书英译与跨章图表编号查找。版本号为 versionCode 25 / versionName 0.0.25。

发布前检查通过：ESLint、TypeScript、127 个测试套件、2,316 项测试、15 个快照，以及 Android arm64 Release 构建。单元测试覆盖新工具、空回答、停止、引用格式、502 重试、请求前缀在各协议下逐轮不变、岔路进出后调用与结果配对，以及修复旧版本留下的落单调用。用真实模型 gpt-6.1-sol（经中转服务）在 Chat Completions 与 Responses 两种协议下各跑了 20 道阅读问答及多轮流程，并在 Responses 下走完「提问 → 开岔路 → 岔路内追问 → 回主线 → 再问两轮」，均无报错。中转服务的缓存命中时有时无，缓存改善以离线比对相邻请求的相同前缀为准：岔路内追问约 83%，回主线约 87%，回主线后再问约 86%。本版未在模拟器或真机上实测，也未用 Anthropic Messages 协议的真实模型测试。
