# Pagewise v0.0.15

Android Preview：让导入后的学习路线从正文开始，修复真实长书的章节组织和内容遗漏，腾出更多阅读空间。

- 学习路线与完整目录分开；前言、附录默认选读，封面、版权、参考文献等资料不计学习进度。可以逐节纳入或移出，开始学习、下一节和书架进度保持一致。
- 修复逐页数字书签被当成章节、分部目录重复成章、相邻习题标题合并、Part 下层级错位，以及附录题解跑到正文的问题。目录概览正确统计 Part 内的正文章节。保留编号疑问和原文核对入口。
- 保留 MinerU 的参考文献、页脚注释与边注。检测到内容却未返回可读文字的整页，在重排中保留原 PDF 图像并明确提示。
- 显式换章正确进入选定章节；EPUB 连续阅读不再提供无效的原版切换。伴读常驻两个快捷动作，键盘弹出时收起次要控件；闪卡评分固定在底部。
- 五套皮肤统一阅读模式名称，改善辅助文字对比度；书架长标题限两行，清理明确的下载重复后缀，隐藏 Unknown 作者占位。
- MinerU 凭据或配额不可用时，所有等待书籍显示暂停原因，已经接受的解析批次仍保留。

验证：6 本真实 PDF、2,879 页、18 个 MinerU 分片全部完成；修复后 21,908 个内容块均有唯一阅读归属。指定的 `gpt-6.1-sol` 在六本书各完成一次实际讲解，17 个来源引用验证通过，0 个无效引用，阅读/伴读切换位置持久化通过。

生产 Release APK 脱离 Metro 冷启动通过；六本均走通书架、目录、小节、重排阅读及原版 PDF，原页全部正常加载。深色模式、130% 字号的书架走查通过。

ESLint、TypeScript、116 个测试套件、2,102 项测试、15 个快照通过，含六本真实书与 AIMA 私有夹具；这些私有书籍不随仓库分发，远端 CI 会跳过相关用例。Android arm64 Release 构建通过。

已知边界：机器学习实战 6 页、因子投资 1 页、AFML 1 页的云端 OCR 未给出完整内容，当前保留原页图像；这些页的内部文字不能作为成功 OCR 的文字检索或选段引用。空白页不进入重排。未逐字校对全部原书，也未覆盖实体机长期使用。
