# Pagewise v0.0.4

Android 预览版，优化 AI 回答的流式呈现：文字按阅读节奏逐步显示，新字从模糊渐变为清晰，引用卡与公式整体淡入。未闭合的 Markdown 标记会等待内容完整后再呈现；生成结束后，较长的剩余内容可以通过「显示全部」立即展开。

修复回答尾部停在输入区下方的问题：跟随实际内容底部，不再依赖 FlatList 缓存的行高；自动滚动结束不会误取消跟随。用户拖动阅读旧消息时暂停自动滚动，回到底部或发起新一轮提问时恢复。流式消息保存后保留同一列表条目，避免动画重置和重复显示。

完整检查通过：82 个测试套件、1248 项测试、15 个快照，包含流式交接、渐显、Markdown、自动滚动与手势回归。

模拟器 Demo 复验通过：纸感与苹果风回答尾部完整可见；纸感手动翻阅旧消息后，发起新一轮恢复跟随。Android arm64 debug / release 构建通过，release APK 签名校验通过。

安装包为 `Pagewise-v0.0.4-android-arm64.apk`，最低 Android 7.0（API 24），versionCode 为 4，无需 Metro。沿用此前预览版的开发签名，附 `SHA256SUMS` 校验文件。
