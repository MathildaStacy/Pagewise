# Pagewise v0.0.21

Android Preview：在书页内调整阅读显示，切换双语模式和核对出处时保留段落，长篇 AI 讲解更方便阅读与复制。

- 阅读页常驻「翻译本节」「阅读设置」，本节对话与精修收进「阅读工具」。字号、浅色与深色可在书页和双语阅读内调整，并保存在本地。
- 双语阅读的模式、进度与设置固定在顶部；中文、原文和中英对照切换以原文段落定位，等待新布局测量后恢复位置。对照模式明确标注语言，未译段落保留原文及状态提示。
- 查看出处作为第二层打开，底下的译文继续保留；返回时维持原来的阅读方式和位置，正在进行的翻译不被取消。
- 实际讲解入口统一展示原文与「AI 讲解」，生成、完成、中断、停止及重试均使用讲解文案。
- 翻看旧消息时暂停跟随，提供「回到最新讲解」。完成的回复支持文字选择和整条复制，保留公式、引用与列表编号；宽屏讲解正文居中并限制行宽。

包含 v0.0.20 的电子书排版、逐段双语阅读与中文扫描图表重绘。版本号为 versionCode 21 / versionName 0.0.21。

发布前检查通过：ESLint、TypeScript、124 个测试套件、2,229 项测试、15 个快照，以及 Android arm64 Release 构建。手机、横屏、宽屏、深色与大字号的原生画面见 [10 项体验优化与验收](../evidence/reading-pm-audit-20261103/README.md)。

本轮单段在线讲解曾遇到现有 AI 服务连接失败，已验证中断与重试界面；在线完成结果未实测成功，完成态另有实际页面入口的自动回归覆盖。
