# Pagewise v0.0.17

Android Preview：修复真实书籍中的公式源码外露、表格公式未排版、HTML 上下标和横滑问题。

- 扩充离线 MathJax 支持，向量、常用数学符号和文本命令能够正常排版；无需联网加载公式资源。
- 正文上标、下标保留语义显示，阅读预览、展开表格与精修表格对照统一使用富文本单元格。
- 长公式可以直接在符号上横滑，表格可以滑到末列，减少与段落菜单及底部弹层的手势冲突。
- 苹果风在 Android 使用不透明弹层回退，消除底层正文透字；提高浅色辅助文字对比度。

已有书籍无需重新导入。六本真实书籍按生产配置扫描，原先 241 次公式渲染失败中 238 次已恢复；包括新支持的上下标，共检查 10,074 次表达式，仍有 3 次源 TeX 损坏需要原页核对。渲染修复不会自动改正原有 OCR 的负号、变量或其他内容错误。

验证：ESLint、TypeScript、117 个测试套件、2,116 项测试、15 个快照通过；Android arm64 Release 构建通过，与 v0.0.16 签名一致。原生五皮肤回归详见 [修复与验收记录](../reader-rendering-fixes-v0.0.17.md)。

安装包：`Pagewise-v0.0.17-android-arm64.apk`，versionCode 17 / versionName 0.0.17，最低 Android 7.0（API 24）。沿用 Android Preview 开发签名，附 `SHA256SUMS`，标记为 prerelease。
