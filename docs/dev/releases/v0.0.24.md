# Pagewise v0.0.24

Android Preview：中文原书的「翻译本节」和单段翻译改为译成英文；单段「解释」能带上其他章节里被提到的表格、图和公式。

- 中文原书（如《因子投资：方法与实践》）的「翻译本节」、双语阅读与单段翻译改为译成英文，不再出现中文译中文。按正文判断原文语言：中文段落里夹带的英文术语和公式不影响判断，代码和公式块不参与；含假名或谚文的按日文、韩文处理，仍译成中文。
- 中文原书的双语切换显示「中英对照 / 英文 / 原文」，副标题为「· 英文」。英文书的请求与缓存键保持不变，v0.0.23 及以前的译文照常命中。
- 单段「解释」新增全书图表编号索引：段内提到的「表3.19」「图 4-3」「式（2.5）」「Figure 4.1」在本节及前后两页找不到时，到全书索引里找。写明「第 N 章」或带章号的编号按该章查找，否则先找当前章；不带章号的编号（如「表 5」）只在全书唯一时使用。
- 附近找到的仍优先；每次最多附 3 项，表格最多 3,000 字符；来自其他章节的项注明所在小节。索引按书缓存，书的内容变化后重建，图题仍与对应的图配对。

包含 v0.0.23 的讲解上下文、逐句讲解、岔路小节续读与多词检索。版本号为 versionCode 24 / versionName 0.0.24。

发布前检查通过：ESLint、TypeScript、125 个测试套件、2,262 项测试、15 个快照，以及 Android arm64 Release 构建。两项改动由单元测试覆盖：语言判断、中文小节在三条翻译路径上都请求英文、英文书沿用 v0.0.23 的缓存键、双语界面文案，以及跨章编号查找、附近优先、数量与长度上限。本版未在模拟器或真机上实测，也未取得真实模型的回答。
