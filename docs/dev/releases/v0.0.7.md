# Pagewise v0.0.7

Android 预览版，新增 Meta、Google、Win11 三套品牌 UI，支持浅色与深色。颜色、图标、圆角、布局与交互对齐对应设计原稿；保留 main 的新应用图标和 Android 禁用原生模糊的兼容处理。

修复问书架范围首次点击、继续提问的输入聚焦与草稿保留，以及原版与重排往返后的阅读定位。Google 重排保持整节一个连续 article，恢复原稿内距、圆角与浅色阴影；PDF 便签保留 32dp 可见圆片，补齐 48dp 透明点击区域。补齐系统大字体下的控件伸展与换行，并修复 Android 长占位文案裁切。真实导入的章节标题已带编号时不再重复添加，尚未生成导读时也不再重复显示默认标题。修复覆盖升级后偶发的页面跳转失效，导航引用按界面实例隔离。

合并 main 后，ESLint、TypeScript 与完整测试通过：89 个测试套件、1,764 项测试、15 个快照；另有 1 套、2 项依赖未提供的私有 MinerU fixture 的测试跳过。Android arm64 release 构建及签名校验通过。

三品牌明暗色主流程及 360dp / 系统字号 2 已做 Android 原生回归。两份用户 PDF 各通过连续 50 页本地渲染。本轮发布包另验收 v0.0.6 覆盖升级、书库与外观偏好保留、冷启动，以及三品牌明暗色下的本地 EPUB 阅读。iOS 原生与真实远端 AI / MinerU 联调不计入本轮验收。

安装包为 `Pagewise-v0.0.7-android-arm64.apk`，最低 Android 7.0（API 24），versionCode 7，无需 Metro。沿用 Android Preview 开发签名，可覆盖此前预览版，附 `SHA256SUMS`。本版仍为 prerelease。
