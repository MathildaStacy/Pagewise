# Pagewise v0.0.16

Android Preview：PDF 导入默认开启 OCR，减少使用 PDF 文字层时发生的负号、变量和数学符号遗漏。

- 所有新导入的 PDF 默认开启 OCR，包括有文字层的文件；仍支持手动关闭，切换解析模型会保留用户选择。EPUB 继续本机解析。
- 更正导入页“书有文字层，一般不需要”的提示，说明开启与关闭 OCR 对公式和符号的影响。
- 原页兜底提示改为“此页未生成独立的可读内容，已保留原页图像”，避免把跨页合并误报为 OCR 失败。
- 补充六本真实 PDF 的 OCR 专项报告，更正此前“8 页 OCR 缺失”：7 页内容合入前页，1 页脚注被误标为页眉后过滤。

实际云端对照完成 21 个 VLM 单页结果：开启 OCR 后，AFML p.62 的希腊字母和指数、机器学习实战 p.256 的 `Ap ≤ b`、利率讲义 p.15 的 `−0.002` 恢复正确。另 7 个 pipeline 对照任务在专项复核最后查询时仍排队，未计入效果结论。

升级不会自动重新解析已有书籍。公式编号错位、跨页来源定位、页眉误分类和双栏索引顺序仍有待处理；本版没有宣称全书公式均已正确。

验证：ESLint、TypeScript、116 个测试套件、2,104 项测试、15 个快照通过，含本机六本真实书与 AIMA 私有夹具。私有书籍不随仓库分发，远端 CI 会跳过相关用例。Android arm64 Release 构建及签名校验通过，与 v0.0.15 签名一致。

实际 Release APK 从 v0.0.15 覆盖安装，脱离 Metro 冷启动通过，原有六本书仍保留。经系统文件选择器打开真实 PDF 单页，确认 OCR 默认开启、关闭后的提示正确、切换模型保持关闭；取消导入后书架仍为六本。

安装包：`Pagewise-v0.0.16-android-arm64.apk`，versionCode 16 / versionName 0.0.16，最低 Android 7.0（API 24）。沿用 Android Preview 开发签名，附 `SHA256SUMS`，继续标记为 prerelease。
