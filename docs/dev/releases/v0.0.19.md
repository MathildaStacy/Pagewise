# Pagewise v0.0.19

Android Preview：翻译与段落解释支持本地复用，重复打开无需再次等待生成；长章节翻译中断后可以继续。

- 单段翻译、解释和整节译文保存到本机，相同输入与模型配置直接复用；译文命中后立即完整显示。
- 修改原文、目录、模型、思考档位或服务地址后重新匹配，避免复用不对应的答案。
- 长章节保留已完成的翻译分片，停止后可继续、失败后可重试；“重新翻译”会完整重做，失败保留上一份完整译文。
- 相同并发请求合并执行，单个调用者取消不影响其他调用者；本地命中不会新增 token 用量。
- 非对话 AI 请求将固定规则、目录和变化的原文分开，改善供应商 prompt cache 的复用条件。实际命中和费用以供应商报告为准。

设计与规则见 [功能设计](../ai-task-cache-product.md) 和 [技术方案](../ai-task-cache-technical.md)。数据库升级保留现有学习记录和旧译文；旧版译文没有模型身份，首次使用时需重新生成可验证的新版本。

验证：`npm run check` 通过 ESLint、TypeScript、121 个测试套件、2,179 项测试和 15 个快照；新增缓存模块行覆盖率 100%。Android arm64 Release 构建、APK 签名校验、v0.0.18 覆盖升级及冷启动通过，原有六本书、目录和阅读入口保持可用。本地缓存、取消、分片续做、配置失效和备份恢复通过自动化测试；本次未实测真实供应商缓存收益。
