# Pagewise v0.0.2

Android 预览版，修复 v0.0.1 双原型检查中记录的八项问题：阅读图片点击与段落无障碍名称、Apple 段落菜单和已讲标记、书封面、Paper 底栏图标和确认框、两套地图的学习中状态。

阅读图片点击现在打开该段的操作菜单；图片没有独立查看动作时不再宣称可以查看大图。段落无障碍名称包含正文和当前或已讲状态。

安装包为 `Pagewise-v0.0.2-android-arm64.apk`，最低 Android 7.0，沿用开发签名；`SHA256SUMS` 包含校验值。Android versionCode 为 2。

本地完整检查通过 80 suites / 1195 tests / 15 snapshots；版本元数据调整后另通过存储测试。Android arm64 构建通过。

这仍是预览版：完整 TalkBack 流程、四主题长内容与流式切换等整体验收尚未完成，不代表两套 UI 已逐页与原型完全一致。此前确认边界见 `docs/dev/evidence/t4/review-v0.0.1.md` 和 `docs/dev/evidence/t12/acceptance-status.md`。
