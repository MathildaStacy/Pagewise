# Pagewise v0.0.22

Android Preview：书页显示当前位置，双语阅读从正在读的段落打开并记住阅读方式，中断后可继续翻译；AI 回答中的表格按表格显示，讲解与译文可整段复制。

- 书页和讲解页的长章节标题最多显示两行；重排模式在工具栏显示当前页与本节段落位置（如「p.50 · 本节 1 / 3」），原有学习进度提示保留在第二行。
- 从书页打开「翻译本节」时定位到正在读的段落，关闭后书页回到译文中读到的位置；同一节再次打开时沿用上次选择的中英对照、中文或原文。
- 双语阅读顶部显示当前页和段落位置；模型设置收成简短的「模型」入口，完整名称保留在无障碍提示中。
- 未全部翻完时显示「部分已翻译」而非「翻译完成」，提供「到未译段落」，底部按钮改为「继续翻译」，只补译缺少的段落。
- 单段讲解与翻译完成后可「复制讲解」「复制译文」，并提示复制结果。
- AI 回答中的 Markdown 表格渲染为可横向滑动的表格，单元格内的引用、公式与代码保持可用；生成中未写完的表格行暂不显示，复制时按制表符保留表格结构。书架问答中的表格引用同样标注出处。
- AI 生成讲解期间收起暂时不可用的快捷学习按钮，只保留输入和「停止」。

包含 v0.0.21 的页内阅读设置、双语切换定位与长对话交互。版本号为 versionCode 22 / versionName 0.0.22。

发布前检查通过：ESLint、TypeScript、124 个测试套件、2,231 项测试，以及 Android arm64 Release 构建。Pixel 10 Pro 模拟器上以《ML-Trading》第 3.2 节实测：两行标题、重排位置提示、从第 2 段打开双语阅读、在线翻译完成为「翻译完成 · 3 / 3」、重新打开保持中文模式、生成中收起快捷操作，以及 L1/L2/L3 对比表格带页码引用的显示。复制按钮写入剪贴板的内容由单元测试覆盖，未在设备上逐项核对。
