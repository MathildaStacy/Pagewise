# Pagewise v0.0.5

Android 预览版，修复苹果风部分地图、听讲和阅读页面的整屏灰蒙。Android 改用已有的半透明材质填充，避免原生模糊污染整页颜色；iOS 继续使用原生模糊。

补齐新增闪卡的原生回读：编辑正反面、保存本节、在次日复习中重新打开并翻面，内容与 SQLite 一致。TalkBack 中文书名、操作顺序和控件状态已通过录音转写核对，原始录音和同音转写误字保留；人工音质、语调和长篇听感仍待核对。详细范围见 [补验报告](../evidence/t4/acceptance-v0.0.5.md)。

本版同时包含 main 已有的设计原型和历史验收记录；独立 worktree 中的新皮肤开发未纳入。完整检查为 83 个测试套件、1253 项测试、15 个快照，另有 ESLint、TypeScript 和 Android arm64 release 构建。

安装包为 `Pagewise-v0.0.5-android-arm64.apk`，最低 Android 7.0（API 24），versionCode 5，无需 Metro。沿用预览版开发签名，附 `SHA256SUMS`。本版仍为 prerelease，既有验收缺口按状态矩阵保留。
