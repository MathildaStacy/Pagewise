# Pagewise v0.0.8

Android 预览版，完善阅读、AI 对话与代码显示，包含此前 main 的学习连续性、笔记、复习卡管理和备份恢复改进。

- 输入框适应软键盘，保持当前输入和发送操作可见，覆盖页面、对话框和底部弹层。
- 获取模型时自动识别内置搜索、工具调用、多模态和推理能力；刷新保留手工配置。
- 章节支持新建和切换独立对话，各自保存消息、进度和模型选项；首页显示所有对话及所属书籍、章节。旧消息自动迁移。
- 英文书支持整节 AI 中文翻译，覆盖完整原文并保留代码和公式；支持缓存、重新翻译、取消和失败重试。
- 讲解、对话、翻译和问书架支持选择模型、推理强度与内置搜索，选项随模型能力调整。
- 代码支持多语言高亮、等宽字体、固定行号、横向滚动、复制和全屏；保存讲解或翻译为便签后仍保留代码及语言。

修复快速修改参数互相覆盖、切换对话串配置，以及便签保存丢失行内代码和代码块格式的问题。验证翻译取消后的迟到响应不会覆盖新结果，重新翻译失败时保留旧译文，多对话和译文可完整备份恢复。

ESLint、TypeScript、100 个测试套件、1,926 项测试和 15 个快照通过；另有 1 套、2 项依赖未提供的私有 MinerU fixture 的测试跳过。五套 UI 皮肤均覆盖深浅色，Android 原生验证键盘避让、代码阅读与对话操作。Android arm64 Release 构建和离线启动通过。真实远端 AI / MinerU 联调及实体机性能不计入本轮验收。

安装包为 `Pagewise-v0.0.8-android-arm64.apk`，最低 Android 7.0（API 24），versionCode 8，无需 Metro。沿用 Android Preview 开发签名；已验证从正式发布的 v0.0.7 覆盖升级，原有两本书和迁移后的对话列表正常显示，冷启动无运行时错误。附 `SHA256SUMS`。本版仍为 prerelease。

详细验证记录：[阅读与 AI 功能验证](../evidence/reader-ai-enhancements.md)。
