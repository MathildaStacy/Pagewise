# Pagewise v0.0.11

Android 预览版，修复 PDF 解析完成后仍显示文字占位封面的问题。

- 使用原始 PDF 的第一页生成真实封面，保存在书籍目录中，清理页面缓存后仍可显示。
- 已导入的 PDF 在下次加载书籍时自动补齐封面，无需重新导入、重新解析或消耗 MinerU 额度。
- 书架、首页、解析进度、笔记和跨书搜索结果共用封面图片，支持全部五套皮肤。原文件缺失或图片加载失败时保留彩色文字占位。

包含 main 的 v0.0.10 阅读、流式翻译和对话列表改进。

ESLint、TypeScript、104 个测试套件、2,004 项测试和 15 个快照通过；保留 1 个套件 / 2 项依赖未提供私有 MinerU fixture 的既有跳过。Android arm64 Debug 与 Release 构建通过；原生 v0.0.10 → v0.0.11 覆盖升级、已有书籍自动补封面、缺失源文件占位、缓存清理和离线显示通过，书籍、对话、学习进度及笔记数据校验值保持一致。

安装包为 `Pagewise-v0.0.11-android-arm64.apk`，最低 Android 7.0（API 24），versionCode 11，无需 Metro。沿用 Android Preview 开发签名，附 `SHA256SUMS`。本版仍为 prerelease。

详细记录：[PDF 封面验收](../evidence/pdf-covers/README.md)。
