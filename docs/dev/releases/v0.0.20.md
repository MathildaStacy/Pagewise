# Pagewise v0.0.20

Android Preview：原文和中文译文以电子书方式阅读，扫描书中的可辨认图表可以经过 AI 识别后清晰重绘。

- 整节翻译进入全屏「双语阅读」，可切换中英对照、中文和原文；手机逐段上下对应，宽屏左右对应。以原文块确定对应关系，支持缓存复用、停止与续译。
- 五套皮肤的默认书籍正文统一为 17sp、1.75 行距，按标题、正文、图注和脚注区分层级；跟随系统及应用阅读字号，支持深浅色。
- 表格保留合并单元格、公式与上下标，按内容分配列宽和行高；修复大字号末行裁切和展开表格时误触段落菜单。列表编号和原书小图按真实内容呈现。
- 「精修本节 → 原页复核」支持图片中的表格、柱状图、折线图、散点图和简单结构图。采纳后的图表使用原生矢量绘制，保留原图对照、撤销和双语阅读中的同一份图表。
- 曲线明确标注为按扫描图估读。无效结构会反馈重试；模型指出疑点时撤回对应图片建议。照片、无法辨认、双轴、多面板和外框分组等无法忠实表达的图保留原始内容。

图表处理按小节执行，通过预览选择后采纳。此次用《因子投资：方法与实践》和《打开量化投资的黑箱》的真实章节验证柱状图、多条折线、结构图与中文表格，并非整本书逐页校对或全部图表重绘。已有 MinerU 解析结果可以继续使用。

真实书籍与原生画面见 [阅读与双语排版验收](../evidence/ebook-reading-20261103/README.md) 和 [中文扫描书与图表验收](../evidence/scanned-reading-20261103/README.md)。版本号为 versionCode 20 / versionName 0.0.20。

发布前检查通过：ESLint、TypeScript、124 个测试套件、2,222 项测试、15 个快照，以及 Android arm64 Release 构建；已核对 APK 中的版本号。
