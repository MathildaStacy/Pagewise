# Pagewise v0.0.1

Android 预览版，包含 PDF / EPUB 导入、学习对话、原文与重排阅读、引用、笔记、复习卡，以及 Paper / Apple 两套外观与浅深色切换。

## 安装包

- `Pagewise-v0.0.1-android-arm64.apk`：Android release 构建，arm64-v8a，最低 Android 7.0（API 24），无需 Metro。
- Android 与项目版本统一为 `0.0.1`，versionCode 为 `1`。
- 当前沿用仓库的开发签名，用于本次预览测试。
- `SHA256SUMS` 提供安装包校验值。

## 已验证范围

- 本地 lint、类型检查、80 suites / 1191 tests / 15 snapshots 通过。
- Android debug / release arm64 构建通过。
- 用户指定的 Machine Learning for Trading PDF 共 827 页已解析；三个小节真实学习会话通过。
- 公版 Alice EPUB 导入、真实 AI、清缓存重新解析后的记录保留通过。
- 备份、实际卸载重装恢复及 release 正式恢复入口通过，13 张表、2 份原件和 552 张图片核对一致。
- Paper / Apple 主页面四主题已补 44 张原生截图；已有部分 Reader 与浮层截图和 37 张浏览器原型参考。

## 验收状态

整体验收尚未完成，两套 UI 尚未获得与原型逐页完全一致的确认。完整四主题学习与浮层走查、30 条原生引用点击、TalkBack、隔三天续学、PDF 重新解析迁移和 Anki 实际导入仍有缺项。模拟器 release 冷启动未达到 1.5 秒目标；实体机性能与 Anthropic 专项尚未验证。
