# Pagewise v0.0.23

Android Preview：单段「解释」边生成边显示，并带上所在小节、前后段与段内提到的图表；长段落可以只讲一句、带着这一句继续问；逐段翻译参照上一段保持术语一致；从地图或岔路进入的小节读完可接着读下一节；全书搜索支持多词检索。

- 从地图「看原文」或岔路进入的小节，读到末尾显示「下一节 · 3.5.3 动量因子实证」，并提示「伴读仍停在 1.1.1」；接着读不改变主线进度。
- 讲解完成后折叠的「AI 举例 / 补充推导」显示展开箭头和一行预览，不再像一张空卡片。
- 单段「解释」改为流式显示，不再等整段结果返回才出现内容；已缓存的解释仍一次显示。
- 逐段翻译时附带所在小节标题与上一段的原文和译文作参照，同一节的术语和指代保持一致；参照不进入缓存键，已有译文照常命中。
- 单段解释的上下文改为章节路径、页码、本节导读、前两段与后一段，以及精简目录（各章标题 + 当前章完整小节，标出「← 当前」，去掉封面、版权等资料节点）。《因子投资》3.5.2 首段的上下文由 8,465 字符降到 2,096 字符。
- 表格以 HTML 和表题、图以图题和重绘数据随解释发送；段内提到的「表3.19」「图3.20」「式（3.1）」在本节及前后两页内按编号找到后一并发送。
- 解释面板新增「只讲一句」：长段落按句列出，点一句只讲这一句（整段仍作上下文），可「讲整段」返回；带到伴读继续问时，引用条和对话气泡显示所选句子。
- 从书页引用其他小节提问时不再先为主线小节整理路线图；请求标明岔路小节，书的地图同时展开该小节所在章。
- 修正每轮对话指令 `<turn>` 被发送两次的问题，token 估算同步修正。
- 全书搜索（AI 的 `search_book` 与地图搜索）按空格拆词，按命中词数、出现次数排序并给标题加权；按章过滤改为在查询中按小节树精确匹配（支持「3」「ch3」「第3章」）；参考文献、目录等资料类小节排在最后。「动量 崩溃 尾部风险」由 0 条变为 3 条，「动量」前 8 条全部来自 3.5.1–3.5.2。

包含 v0.0.22 的阅读位置、翻译续译与 AI 表格。版本号为 versionCode 23 / versionName 0.0.23。

发布前检查通过：ESLint、TypeScript、125 个测试套件、2,245 项测试、15 个快照，以及 Android arm64 Release 构建。Pixel 10 Pro 模拟器上以《因子投资》（中文 PDF）和 *ML-Trading*（英文 PDF）核对了设备实际发给 AI 的请求：解释上下文、图表 refs、逐句 `focus`、翻译参照，以及每轮只有一个 `<turn>`。验收时两个已配置的 AI 服务均返回「无效的令牌」，界面状态改由内置 Demo 回复驱动，真实模型的回答质量未验证。问题清单与前后截图见 [书页、翻译、AI 讲解与上下文检索的 10 项优化](../evidence/reading-retrieval-audit-20261104/README.md)。
