Windows 11 风

WinUI 3：背后是被壁纸染色的 Mica，底栏和通知是毛玻璃 Acrylic；控件 4px、浮层 8px 圆角，按钮底边略深一像素；选中项统一用一根强调色短药丸。读书 / 听讲是 Segmented 控件，岔路是 InfoBar，已解决的岔路是 Expander，弹出面板像 ContentDialog，自己的提问像「手机连接」里发出的短信。只做了「听讲」和「读书」两个页面。

可以试试

  1. 点讲解里的 p.103：从底部弹出原书预览，再点「在读书模式打开」
  2. 点「懂了，下一步」「这步熟，跳过」，看顶部路线图和进度条
  3. 输入"这跟前面的 3.4.2 有什么关系"，进入岔路，再点「回到主线」看折叠
  4. 切到「读书」：点段落 → 「从这里开始讲」；点黄色便笺
  5. 讲完第 4 步 → 「懂了，下一节」看闪卡草稿
