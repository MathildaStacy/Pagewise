# Win11 风原型源文件（2026 版）

`../prototype-win11.html` 是由这里的文件拼出来的单文件原型，直接用浏览器打开即可（不联网、不用网络字体）。其他皮肤（`../prototype.html` 纸感、`../prototype-apple.html`、`../prototype-google.html`、`../prototype-meta.html`）保持原样。

视觉依据是 `../explore/windows11-2026.html`（那份只做了「今天」和「听讲」两页），这里把它扩成**完整原型**：所有页面、所有浮层、空 / 错误 / 加载状态都画出来了，另外有一个**组件库**页面，列出每个组件的各种状态和对应的 CSS class。目标是让前端能力一般的实现者也能照着做出来：**不清楚的地方先打开组件库（控制台 →「我的」→ 组件库，或 `#组件库`），再看这里的规则。**

流程、数据、文案的依据：`docs/dev/02-skins.md`（皮肤之间什么必须一样、Token、组件契约）、`docs/dev/03-screens.md`（页面清单和 §12 页面状态）、`docs/dev/05-engine-ai.md`（听讲按「步」推进）。

```bash
python3 build.py   # 生成 ../prototype-win11.html
```

打开 `prototype-win11.html#听讲`、`#读书`、`#书的地图` 等可以直接跳到某个页面（名称见控制台的「页面」列表）。

## 和其他皮肤的区别

功能比其他皮肤多，这些是 Win11 稿新增的，实现时按这里做：

| 新增 | 说明 |
| --- | --- |
| 「今天」Tab | 5 个 Tab 变成 今天 · 书架 · 复习 · 笔记 · 我的；「今天」是默认首页：问候 + 问书架入口 + 继续听讲大卡 + 闪卡 / 连续学习两张小卡 + 书架横排 |
| 问书架 | 跨书提问：书本筛选胶囊、推荐问题、最近问过；回答带书名和页码，只搜已解析的部分 |
| 学习记录 | 连续天数 + 今日目标圆环、本周柱状图（彩虹渐变）、月历热力图、汇总数字 |
| 新手引导 | 首次启动 4 步：欢迎 → AI 服务 → MinerU Token → 讲解偏好，每步都能跳过 |
| 组件库 | `ui-kit.js`：颜色 Token、字体、按钮、输入、选择、提示、列表、thread 卡片、浮层、图标，全部可点 |
| 页面状态 | 控制台「页面状态」可以打开：空书架、未配 AI、未配 Token、Token 过期、断网、AI 出错、小结生成中 / 失败 |

## 视觉规则

| 部位 | Win11 风 |
| --- | --- |
| 外框 | Android 手机（打孔摄像头、细手势条），放在 Win11 壁纸上；右边是 Win11 窗口样式的原型控制台，底下一条任务栏只是装饰 |
| 材质 | 四层：壁纸 `--wall` → 手机底 Mica `--mica`（浅蓝紫渐变）→ 半透明卡片 `--card`（三档 `--card-lo / --card / --card-hi`）→ 亚克力 `--acrylic`（Tab 栏、浮层，`backdrop-filter: blur`） |
| 顶栏 | 根页：小字副标题 + 30 号 Display 大标题，右侧圆形图标按钮；push 页：「←」+ 居中标题（可带一行小字副标题） |
| Tab 栏 | **悬浮**的亚克力胶囊条，离底边有间距；选中项强调色、图标下方短指示条；复习有红色数字角标 |
| 读书 \| 听讲 | 顶栏下方的文字标签（SelectorBar），选中项浅底 + 下方强调色短条；右侧「AI 看到的内容」 |
| 卡片 | 16–20 圆角、1px 细描边、轻阴影；区块标题 15 号半粗在卡片外，右侧可带灰色说明或链接 |
| 按钮 | **药丸形**（999 圆角）：主按钮强调色、次按钮半透明白、AI 按钮彩虹、危险红字；高 40，小号 `.btn.sm` 32；悬浮的「导入」FAB 高 48 |
| AI 相关 | 统一用 Copilot 彩虹 `--ai`（蓝 → 紫 → 粉 → 橙）：问书架框、听讲输入框（带外发光，聚焦时变亮）、AI 头像、AI 举例、导读、续学回顾、当前步进度 |
| 图标 | 两套：线条图标 `I(name)`（按钮、列表行尾）和 Fluent 3D 彩色图标 `T3(name)` / `I3`（卡片头、列表行首的彩色小方块） |
| 听讲 | 路线图是分段进度条；AI 回答**不加气泡**、左侧彩虹头像；用户提问是蓝色气泡；岔路用紫色（左侧紫竖线）；原文引用卡片高亮关键词；本节小测可以点着答 |
| 读书 | 白色书页卡片（宋体、公式用数学字体），讲过的段落左侧竖线，问答便签是黄色胶囊 |
| 浮层 | 底部 Sheet（24 圆角、把手、可下滑关闭）；对话框居中；Toast 在 Tab 栏 / 输入框上方 |
| 深色 | 所有颜色都有深色值（`:root[data-theme=dark]`），控制台可以切换；彩虹和语义色在深色下用更亮的一档 |

语义色（浅色值，深色见 `base.css`）：主线 `--accent #0067C0`、岔路 `--detour #7B4FE0`、卡点 `--stuck #E06A00`、对 `--ok #0E8A4F`、错 `--bad #C42B1C`、补充推导 `--derive #0E8073`、高亮 `--highlight`、便签 `--pin`。每种都有 `-bg`（浅底）和 `-ink`（小字用，保证对比度）。

## 实现时容易踩的坑

- **`.ai` 这个 class 有两种用法**：thread 里的 AI 回答是 `div.ai`（纵向 flex），按钮 / 进度条 / Tag 上的 `.ai` 只表示「用彩虹」。样式里 thread 的规则写成 `div.ai:not(.bar)`，别写成裸的 `.ai`，否则 `.btn.ai`、`.tag.ai` 会变成上下排列。
- **彩虹描边**用 `::before` + `mask-composite: exclude` 画 1.5px 的渐变边框（见 `.ask::before`），不是 `border-image`（`border-image` 画不出圆角）。
- **输入框聚焦**靠外层 `.glow` 变亮表示，输入框本身去掉 `:focus-visible` 的方框。
- **半透明卡片**要放在 Mica 底上才好看；如果目标平台不支持 `backdrop-filter`，用 `--card-solid` / `--acrylic-solid` 这两个实色兜底。
- Tag、列表副标题这类小字，颜色一律用 `-ink` 那一档，不要直接用前景色。
