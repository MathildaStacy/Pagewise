# 书页排版风原型源文件

`../prototype-editorial.html` 是由这里的文件拼出来的单文件原型，直接用浏览器打开即可（不联网、不用网络字体）。其他皮肤（`../prototype.html` 纸感、`../prototype-apple.html`、`../prototype-google.html`、`../prototype-meta.html`、`../prototype-win11.html`）保持原样。

```bash
python3 build.py   # 生成 ../prototype-editorial.html
```

这套皮肤从 Win11 稿（`../prototype-win11/`）复制而来：**页面、流程、数据、文案和交互都没变**（「今天」Tab、问书架、学习记录、新手引导、组件库、页面状态都在），只重做了视觉层。打开 `prototype-editorial.html#听讲`、`#读书`、`#书的地图` 等可以直接跳到某个页面。不清楚的地方先看组件库（控制台 →「组件库」，或 `#组件库`）。

## 参考了什么

| 来源 | 借了什么 |
| --- | --- |
| Edward Tufte 的书 / tufte-css | 细线代替方框和阴影；旁注（问答便签做成页边的「注」）；图注用斜体衬线 |
| Stripe Press | 衬线标题、大留白、素色布面封面、只有一个强调色 |
| 电子墨水阅读器（Kindle、reMarkable、Daylight） | **只借配色基调**：低饱和的米白纸色和暖墨色，不用纯白、纯黑；深色是暖炭灰底 + 米色字 |

## 三条原则

1. **层级靠字号、字重和细线**，不靠阴影和色块。平面上没有阴影，只有浮层（Sheet、Dialog、段落菜单、Toast）有。
2. **原书和 AI 一眼分开**：原书是宋体，排在比纸底亮一档的「书页」上（`--paper`）；AI 讲解是黑体，左边一条 1px 朱色细线，回答上方是一枚朱色「讲」字小印。你的提问右对齐、浅底、上方小字「问」。
3. **一个强调色**：墨蓝 `--accent` 是主线（已讲、链接、引用）；朱色 `--ai` 只标 AI（小印、当前步、导读、续学回顾）；其他语义色都是低饱和的墨水色。主按钮是墨色实底（`--btn`），不是强调色。

## 视觉规则

| 部位 | 书页排版风 |
| --- | --- |
| 外框 | Android 手机放在「书桌」上（`--desk`，带很淡的纸纹）；右边的原型控制台是一页版权页式的说明，不是窗口 |
| 顶栏 | 根页像杂志刊头：字距拉开的小字（日期）+ 32 号衬线大标题 + 下方 1.5px 墨线；push 页「←」+ 左对齐 17 号衬线标题 |
| Tab 栏 | 通栏贴底，顶部发丝线；选中项墨色 + 顶部 2px 墨线（像书签）；复习角标是朱色 |
| 读书 \| 听讲 | 文字标签，选中项墨色 + 下划线；小型分段（原版 / 重排）是细线框，选中项墨色实底 |
| 列表 / 卡片 | 分组列表 = 上方一条墨线 + 行间发丝线，没有底色和圆角；区块标题是 11 号、字距 .16em 的小字。卡片只是一圈发丝线 |
| 数字 | 大数字用衬线（连续天数、闪卡数、Token 数）；表格里的数字用 tabular-nums；页码用斜体衬线 |
| 按钮 | 3px 圆角矩形：主按钮墨色实底、次按钮细线框、岔路紫底、危险红字、文字按钮带下划线 |
| 听讲 | 步标题像书的小节标题（上方墨线、衬线 20 号、右侧斜体页码）；引用是脚注式的斜体小字 `p.103`；原文引用卡是一小块书页 + 墨蓝左线；推导 / 举例 / 续学 / 建议卡点 / 出错都是「左色线 + 浅底」的注 |
| 读书 | 书页没有圆角，右下有两层很淡的纸边；书眉小字；讲过的段落页边墨蓝细线，正在讲朱色粗线；高亮是荧光笔式的半高底色；问答便签是页边的「注」 |
| 书的地图 | 像目录页：章号是大号斜体衬线数字，节缩进、右侧斜体页码；当前小节朱色 |
| 闪卡 | 一张索引卡：卡纸底色、顶部一条朱线、淡蓝横格 |
| 输入框 | 表单字段只有一条下划线（像在纸上填空）；听讲 / 问书架输入框是细线框长条 + 墨色方形发送键；聚焦时框线变墨蓝，没有外发光 |
| 图标 | 只有一套单色线条图标（1.35 线宽）。`T3()` 沿用 Win11 稿的名字，但画成「线条图标 + 发丝线小方框」，颜色只表达语义 |
| 深色 | 所有颜色都有深色值（`:root[data-theme=dark]`），封面在深色下压暗一点 |

语义色（浅色值，深色见 `base.css`）：主线 `--accent #2F5577`（墨蓝）、AI `--ai #B4532F`（朱）、岔路 `--detour #6E4F7E`（紫灰）、卡点 `--stuck #A2741E`（赭）、对 `--ok #4E6E3E`（苔绿）、错 `--bad #9C3A2E`（砖红）、补充推导 `--derive #3D6B66`（青灰）、高亮 `--highlight`、便签 `--pin`。每种都有 `-bg`（浅底）和 `-ink`（小字用）。

字体：标题和书正文 `--serif`（拉丁字母 Iowan Old Style / Palatino，中文宋体 / Noto Serif SC），界面和 AI 讲解 `--font`（苹方 / Noto Sans SC），公式 `--math`。

## 实现时容易踩的坑

- **`.ai` 这个 class 有好几种用法**：thread 里的 AI 回答是 `div.ai`（纵向 flex），`.btn.ai`、`.tag.ai`、`.bar.ai`、`.note.ai` 只表示「用朱色」。样式里 thread 的规则写成 `div.ai:not(.bar):not(.note)`。
- **`.sh` 也有两种用法**：今天页的区块标题是 `h2.sh`，浮层的标题栏是 `.sheet .sh`，样式都要带上前缀，否则会互相覆盖。
- **细线一律用 `box-shadow: inset`** 画，不用 `border`，这样不改变盒子尺寸；只有虚线（未核实、跳过的步）用 `border`。
- **朱色只用在小面积上**（小印、细线、小字、当前步）。大面积的强调用墨色实底，不要把朱色当主按钮色。
- Tag、列表副标题这类小字，颜色一律用 `-ink` 那一档，不要直接用前景色。
