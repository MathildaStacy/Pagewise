# Meta 风原型源文件

`../prototype-meta.html` 是由这里的文件拼出来的单文件原型，直接用浏览器打开即可（不联网、不用网络字体）。纸感原型 `../prototype.html`（源文件 `../prototype/`）和苹果风原型 `../prototype-apple.html`（源文件 `../prototype-apple/`）保持原样。

这套皮肤从苹果风原型复制而来：页面、导航、流程、数据和文案都没变，只把组件按 Facebook / Messenger / Meta AI 的习惯重做。依据：`docs/dev/02-skins.md` §2（皮肤之间什么必须一样）、§4（Token）、§5（组件契约）。Token 取自 `explore/src/meta.css`（那份探索只做了听讲 / 读书两页，这里只借它的色值和组件味道，不用它的布局，比如「读书 | 听讲」仍在顶栏右侧，没有单独的模式条）。

和苹果风的主要区别：

| 部位 | Meta 风 |
| --- | --- |
| 外框 | Android 手机：打孔摄像头状态栏、44 圆角、细手势条 |
| 顶栏 | 实色白底；根页 26 号粗体大标题（书架是蓝色字标 Pagewise），右侧灰色圆按钮；push 页「←」圆按钮 + 左对齐 18 号粗标题；滚动后出现分隔线，不做大标题收起 |
| 读书 \| 听讲 | 顶栏右侧两个小胶囊，选中项蓝底蓝字（Facebook 筛选胶囊） |
| Tab 栏 | 通栏贴底，顶部细线；选中项蓝色、实心图标、上方短指示条；复习有红色数字角标 |
| 列表 | 灰底 `#F0F2F5` 上的白卡（10 圆角），区块标题 17 号粗体在卡片外，行首图标在 36 灰圆里 |
| 按钮 | 6 圆角矩形：主按钮蓝底白字、次按钮灰底 `#E4E6EB` 黑字、岔路紫、危险红字；chip / 分段 / 标签是胶囊 |
| 听讲 | 快拍式路线图（当前步是 Meta AI 渐变圆环）、步骤标题旁渐变圆环头像、Messenger 气泡（用户蓝、岔路紫）、实色贴底输入区（灰色圆角输入框、蓝色纸飞机） |
| 读书 | 通栏白色书页叠在灰底上；问答便签是评论气泡（黄色圆头像 + 灰气泡）；段落菜单是深色 Messenger 长按气泡条 |
| 浮层 | 底部面板（16 圆角、把手、居中粗标题 + 分隔线、灰圆 ✕，按钮竖排全宽）；对话框是居中白卡、两个等宽按钮（灰取消 / 蓝确认，危险红色）；Toast 是底部深色 snackbar，在 Tab 栏 / 输入区上方 |
| 开关 | Android 式：蓝色轨道、白色圆点 |
| 语义色 | 主线蓝 `#0866FF`、岔路紫 `#7B3FE4`、补充推导青 `#00756B`、AI 举例 Meta AI 渐变（`#0866FF → #7A3FFF → #E64FAF`）、卡点橙、对绿、错红、高亮黄 `#F7B928`；深色模式下文字用更亮的一档，白字填充用 `--xxx-fill` 保证 AA |

| 文件 | 内容 |
| --- | --- |
| `shell.html` | 页面骨架（Android 手机外框、顶栏、Tab 栏、浮层层） |
| `base.css` | L1 Token（浅色 + 深色）、顶栏、Tab 栏、分组列表、按钮、分段胶囊、开关、Sheet、对话框、Toast、段落菜单、控制台 |
| `pages.css` | 各页面样式 |
| `icons.js` | 图标（线条 + Facebook 式实心图标，Tab 选中用实心版） |
| `data.js` | 演示数据（同苹果风原型） |
| `core.js` | 状态、书的地图、复习调度、上下文估算、解析模拟 |
| `ui-base.js` | 路由、顶栏、Tab 栏、浮层（下滑关闭）、Toast 定位、富文本、流式输出 |
| `ui-shelf.js` | 书架、书架搜索、导入、解析设置、解析进度 |
| `ui-map.js` | 书的地图、小节详情、全书搜索 |
| `ui-listen.js` | 听讲流程：按步讲解、跳过、换个说法 / 举例 / 推导、考考我、本节小测、续学、岔路与折叠、自由提问、读书 ⇄ 听讲切换 |
| `ui-study.js` | 听讲 / 读书页：路线图、岔路条、thread、快捷动作和输入框、原文预览、AI 看到的内容 |
| `ui-reader.js` | 读书：原版 / 重排、本节导读、讲过的段落、问答便签、段落菜单、单独打开的读书页 |
| `ui-done.js` | 本节小结 |
| `ui-review.js` | 复习（闪卡翻面、卡点清单）、笔记、导出 |
| `ui-me.js` | 我的及子页、外观（纸感 / 苹果风 / 新谷歌风 / Meta 风） |
| `ui-console.js` | 原型控制台（场景 / 页面 / 深浅色）、启动 |

```bash
python3 build.py   # 生成 ../prototype-meta.html
```

打开 `prototype-meta.html#听讲`、`#读书`、`#书的地图` 等可以直接跳到某个页面（名称见控制台的「页面」列表）。
