# 原型源文件

`../prototype.html` 是由这里的文件拼出来的单文件原型，直接用浏览器打开即可（不联网）。

| 文件 | 内容 |
| --- | --- |
| `data.js` | 演示数据：《人工智能：现代方法（第4版）》目录、示意内容块、讲解脚本、岔路问答、闪卡、卡点 |
| `core.js` | 状态、书的地图、复习调度（Leitner 5 盒）、上下文估算、解析模拟（对应 `docs/STUDY_ENGINE.md` 的简化实现） |
| `ui-base.js` | 路由、浮层、富文本（公式、引用、原图）、流式输出 |
| `ui-shelf.js` | 书架、导入、解析设置、解析进度 |
| `ui-map.js` | 书的地图、小节详情、书签核对、全书搜索 |
| `ui-study.js` | 伴读流程：分段讲解、快捷动作、小测、续学回顾、岔路、自由提问 |
| `ui-study2.js` | 伴读界面、「AI 看到的内容」面板、本节小结 |
| `ui-reader.js` | 阅读器：原版 / 重排、讲过的段落、划词菜单（解释 / 翻译 / 问 AI / 高亮 / 笔记） |
| `ui-review.js` | 复习（闪卡、卡点清单）、笔记（按节、导出） |
| `ui-me.js` | 我的（解析服务、AI 服务、讲解偏好、存储）、原型控制台、启动 |
| `shell.html` | 页面骨架和样式 |

```bash
python3 build.py   # 生成 ../prototype.html
```

打开 `prototype.html#伴读`、`#原文`、`#书的地图` 等可以直接跳到某个页面（名称见原型右侧控制台的「页面」列表）。

演示数据说明：书名和章节目录来自原书；页码、「原文」内容块、讲解、闪卡和示意图都是为原型写的，不是原书文字。AI 回答是预先写好的脚本。
