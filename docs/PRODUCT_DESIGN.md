# Pagewise 产品设计

> 版本 0.2 · 2026-10-28 · 产品经理：Claude · 负责人：boren.fang
> 配套：[伴读引擎规格](STUDY_ENGINE.md) · [可交互原型](design/prototype.html)

## 1. 为什么做

精读一本技术书（比如《人工智能：现代方法》），最难的不是"读完"，而是"读懂"：一段推导卡住了，没人可问；问通用 AI，它不知道你读到哪、书里怎么写的、前面已经讲过什么；问完回到书里，又找不回刚才的位置。

你已经在电脑上验证过一种有效的方式：把书解析成按小节拆好的 Markdown，再让 AI 一节一节地讲，讲完整理成讲义（aima4e-markdown 的 `课程讲义/`）。Pagewise 把这套方式搬到手机上，变成一个"带着整本书的私人老师"：

- **按小节讲**：AI 拿着当前小节的完整原文讲，先讲直觉，再讲定义和公式，最后举例、提问，确认你懂了再讲下一节。
- **随时问**：不懂就打断。回答里的每个说法都能点开，跳回书里对应的那一段。
- **能回头**：讲 A\* 时突然想问"这跟前面的一致代价搜索有什么关系"，AI 会自己翻回 3.4.2 的原文来答，答完带你回到主线。
- **记得住**：每节学完留下摘要、卡点和闪卡。隔几天打开，AI 知道上次讲到哪、你在哪卡过。

文档解析交给 MinerU（公式转 LaTeX、表格、扫描版 OCR、每个内容块带页码和位置），讲解交给你自己配置的大模型。

## 2. 目标和不做的事

| 目标 | 怎么衡量 |
| --- | --- |
| G1 一节一节读懂一本书 | 用 Pagewise 学完《人工智能：现代方法》第 3–6 章，每节都有摘要和卡点记录 |
| G2 回答可追溯 | 回答里引用的原文位置 100% 能跳回书里正确的页和段；没有依据的说法会被标出来 |
| G3 隔几天能接上 | 中断 ≥ 3 天后打开，1 分钟内回到上次的小节和上下文 |
| G4 学过的能留下 | 学完一节后，闪卡和笔记能导出成 Markdown / Anki CSV，格式和现有 `课程讲义/` 一致 |

不做：书城和书籍下载、共享书库、社区、阅读排行、自动翻译整本书、在手机上本地跑 MinerU、代替你写作业。AI 只读书和你的学习记录，**改动学习记录（加闪卡、记卡点、标记学完）都要你确认**。

## 3. 用户

只有一个用户：你自己。后端工程师背景，在手机上利用碎片时间精读中文版技术教材，一本几百到一千多页，公式和算法框图较多。所以：

- 不需要账号体系和后端，书和学习记录都留在手机上（本地优先，和 AShareSim 一致）。
- MinerU 和 AI 都用你自己的 Token / Key，直连官方服务。
- 讲解从"为什么"讲起，但不啰嗦；术语第一次出现时中英对照。
- 手机屏幕小：主界面是"对话 + 随时能看原文"，不是左右分栏。

## 4. 核心场景：伴读循环

| 你会做的事 | 产品要解决的问题 | 对应功能 |
| --- | --- | --- |
| 顺的地方自己读，难的地方让 AI 讲 | 同一节有两种学法，随时切换，位置不丢 | 读书 / 听讲 |
| 打开一本书，从某一节开始学 | 书要先被切成"章 → 节 → 小节"的树，每个小节对应一段页码和内容块 | 导入与解析 · 书的地图 |
| AI 讲这一节 | AI 手边要有这一节的完整原文，一节太长就分段讲 | 伴读 · 讲解规则 |
| 有不懂的就问 | 回答要基于原文，并能跳回原文核对 | 引用 · 原文预览 · 读书 |
| 懂了就讲下一节 | 有一个"主线进度指针"，讲完一节就往前走一格 | 小节小结 · 进度 |
| 突然回到前面某节问关联问题 | 能把前面那一节的原文找回来；问完回到主线 | 岔路 |
| 隔几天接着学 | 进度和学习记录要存下来，不能只靠聊天记录 | 学习记录 · 续学 |
| 过一段时间回顾 | 学过的要点要能复习 | 复习 · 笔记 |

一次典型的伴读（原型里可以完整走一遍）：

1. 书架顶部写着「继续：3.5.2 A\*搜索 · 第 2/4 段」，点进去。
2. 因为距上次 3 天，AI 先用两三句话回顾上次讲到哪、你在"为什么扩展时才判断目标"那里卡过，问你要不要先回顾。
3. AI 讲 A\* 的直觉：把"已经走了多远"和"估计还剩多远"加起来，挑最小的扩展。
4. 讲到 f(n) 时你想自己看看书里怎么写的，切到「读书」，原文停在这一步对应的段落；读完点「从这里开始讲」，又回到「听讲」的同一步。
5. 你问："这跟前面的一致代价搜索有什么关系？"AI 判断这是 3.4.2 的内容，读取 3.4.2 原文，界面出现一条紫色的「岔路 · 3.4.2」提示。
6. AI 答：h(n) 恒为 0 时 A\* 就是一致代价搜索，并引用 3.4.2 和 3.5.2 各一段。你点引用，底部弹出原书那一页，对应段落高亮；看完下滑收起，还在对话里。
7. 点「回到主线」。岔路里的几轮问答在主线里折叠成一行「已解决：A\* 和一致代价搜索的关系（3 条）」，并记进 3.4.2 的学习记录。
8. 讲完 4 步后，AI 出一道检查题。答对后点「懂了，下一节」，AI 生成本节摘要、卡点和 3 张闪卡草稿，你勾选确认，进度指针移到 3.5.3。

## 5. 信息架构

底部 4 个 Tab：

```
书架            复习             笔记            我的
 │               │                │               │
 │               │                │               ├ 解析服务（MinerU Token / 解析档位 / 今日额度）
 │               │                │               ├ AI 服务（服务商 / 协议 / Key / 模型）
 │               │                │               ├ 讲解偏好（讲解顺序 / 每段长度 / 小测 / 术语）
 │               │                │               ├ 存储与备份
 │               │                │               └ 关于
 │               │                ├ 按书 → 章 → 节：摘要 · 问答 · 卡点 · 高亮
 │               │                └ 导出 Markdown / Anki CSV
 │               ├ 今日待复习闪卡（间隔重复）
 │               └ 卡点清单（没完全掌握的点）
 ├ 继续学习卡片（当前书 · 当前小节 · 上次卡点）
 ├ 书列表（进度 / 解析状态）
 ├ 导入 → 解析设置 → 解析进度
 └ 一本书 → 书的地图 → 小节（读书 ⇄ 听讲）
```

学一个小节有两种模式，顶栏一个开关「读书 | 听讲」切换，共用同一个主线进度、岔路和学习记录：

| | 读书（书为主） | 听讲（AI 为主） |
| --- | --- | --- |
| 适合 | 读得顺的小节、自己扫读、看整页的图和表、回头翻书 | 推导密集、领域陌生、碎片时间跟学、跨章串讲 |
| 屏幕主体 | 原书（原版页 / 重排） | AI 按步讲解和对话 |
| AI 在哪 | 页边：本节导读、问答便签、划词浮窗 | 主体；原书在引用后面，点开从底部弹出 |
| 谁推进 | 你翻页，读完点「读完这一节」 | 按本节路线图一步一步讲 |

切换时位置不丢：读书 → 听讲，取屏幕中间的段落，跳到讲它的那一步（还没讲就从这一步开始讲）；听讲 → 读书，停在当前这一步对应的段落并高亮。每本书记住你上次用的模式。

## 6. 功能清单（V1）

### 6.1 导入与解析

- 来源：系统文件选择器（PDF、EPUB），也支持从其他 App"分享到 Pagewise"。
- 识别：页数、大小、是否有文字层（判断是不是扫描版）、是否有书签目录。同一本书按文件内容 SHA-256 识别，重命名或换位置不会重复解析。
- **PDF 用 MinerU 官方精准解析 API**：
  - 上传前弹窗确认：书会上传到 MinerU 服务器解析。
  - 单文件限 200 MB / 600 页，超出就按页拆片（例如 1136 页拆成 1–600、601–1136），结果合并后保持原书页码。
  - 解析模型可选 `vlm`（默认，公式、复杂排版更好）或 `pipeline`（更快）。扫描版自动打开 OCR。
  - 优先解析你要读的部分：可指定从哪一页开始，前面的片先解析，就绪的章节马上能学。
  - 显示今日已用页数（每天 2000 页高优先级，超出后排队变慢但不拦截）。
  - 失败可重试单片；Token 过期、额度不足、文件超限都给出明确原因和处理办法。
- **EPUB 不走 MinerU**：EPUB 本身是结构化的，在本地解析目录和章节。
- 解析结果（Markdown、内容块 JSON、图片）存在本地，之后阅读、讲解、搜索都不需要再联网解析。
- V1 只接官方 API。自建 MinerU 服务地址（例如局域网里 Mac 上跑的 `mineru-api`，书不出家门）放到 M5。

### 6.2 书的地图

- 用 MinerU 输出的标题层级和小节编号（3.5.2 这种）切出"章 → 节 → 小节"树，再和 PDF 自带的书签目录核对。
- 核对不一致的地方（缺小节、标题被识别成正文、层级不对）标黄，让你确认或手动修正：重命名、合并、拆分、调整层级。
- 每个小节记录：编号、标题、页码范围、内容块范围、字数、预计讲解段数、状态（未学 / 在学 / 已学 / 有卡点）、摘要（学完生成）。
- 太长的小节（> 4000 字）按段落边界自动切成若干"段"，一段一段讲；太短的（< 300 字）并入相邻小节。
- 从地图任意小节开始学；已学的小节可以"再讲一遍"或"只看摘要"。

### 6.3 听讲（核心）

- **本节路线图**：进入一节先看到一张路线图：本节分 2–5 步，每步一句话说讲什么、对应哪几页（如「第 2 步 · f(n) = g(n) + h(n) 的含义 · p.103」）。可以从任意一步开始；熟悉的一步点「这步熟，跳过」，跳过的步骤在小结里标出来。讲解时顶部的进度条就是这几步。
- **讲解规则**（可在讲解偏好里调）：先讲直觉 → 再讲定义、公式和算法 → 举一个书里的例子 → 用一个问题确认你懂了。每段讲解控制在一屏半以内。
- **快捷动作**：懂了，继续 · 换个说法 · 举个例子 · 展开推导 · 考考我 · 看原文。最后一段讲完后变成「懂了，下一节」。
- **自由提问**：任何时候都能打断提问。
- **引用**：回答里的关键说法后面带引用标记（如 `p.86`）。点开先从底部弹出**原文预览**：原书那一页，对应段落高亮，看完下滑收起，不离开对话；预览里点「在读书模式打开」才切过去。只允许引用 AI 这一轮实际读过的原文；引用不到原文的说法会标"书中未直接提到"。
- **来源标记**：讲解里 AI 自己补的推导（书里省略的中间步骤）和自己举的例子，用不同的底色和一个小标签（「补充推导」「AI 举例」）和书里的内容区分开，没有标签的部分都能在引用里找到出处。
- **原图和公式**：讲到某张图或某个算法框图时，直接显示书里的原图（MinerU 裁出来的）；公式用 LaTeX 渲染。
- **岔路**：你问到前面的内容时，AI 先对照目录和已学摘要判断是哪一节，再读取那一节的原文来答。界面出现岔路提示条「岔路 · 3.4.2 一致代价搜索」和「回到主线」按钮；主线进度不动。岔路里的问答记进被问的那一节的学习记录。回到主线后，岔路里的几轮问答折叠成一行（「已解决：……（3 条）」，点开可看），主线对话保持干净。岔路最多嵌套 2 层。
- **找不到出处时**：用全文搜索兜底（本地 SQLite FTS），并告诉你"在 p.xx 找到相关内容"。
- **"AI 现在看到了什么"**：顶部一个小标签，点开显示本轮上下文：讲解规则、书的地图、当前小节原文、学习记录、岔路原文、最近对话，各占多少 token，哪些部分命中缓存。
- **结束一节**：AI 起草本节摘要（100 字左右）、卡点（你问得多、答错的地方）、3–5 张闪卡。草稿默认全部勾上，你取消不要的、改写不满意的，保存后入库，进度指针前移。
- **续学**：距上次 ≥ 1 天打开时，AI 先给一段 3 句以内的回顾，并问要不要先复习上次的卡点。

### 6.4 读书

- 两种显示：**原版**（按 PDF 原页渲染，排版和书一致）和**重排**（用 MinerU 的 Markdown 重排，字号可调，公式和表格单独渲染，适合手机）。
- 页面上标出听讲已经讲过的段落（左侧细线）和当前讲到的位置。
- **本节导读**：每个小节标题下一行折叠条「本节讲什么 · 前置：3.4.2」，点开是 3–4 句导读（第一次点开时才生成）。
- **问答便签**：你在某段问过的问题，答完后变成贴在那一段旁边的小便签（「已解决：为什么扩展时才判断目标」），翻回来点开就是当时的结论和对话。听讲里的提问也会贴到答案引用的那一段上。
- 划词 / 长按段落：解释 · 翻译 · 问 AI · 从这里开始讲 · 高亮 · 记笔记。"解释"在底部弹层里直接回答（200 字以内），要多问几轮就"带到听讲里继续问"。「从这里开始讲」切到听讲，从这一段所在的那一步讲起。
- 从听讲切过来或点引用打开时，定位到对应页并高亮那个内容块（用 MinerU 给的位置框）。
- 读到本节末尾出现「读完这一节」：和听讲一样走结束一节的流程（摘要、卡点、闪卡草稿，可选一道检查题），主线进度前移。
- 目录、页码跳转、全文搜索。

### 6.5 复习

- 闪卡：来自每节学完时你确认过的草稿，也可以在笔记里手写。按间隔重复安排复习（忘了 / 模糊 / 记得，见引擎规格 §9）。
- 每张卡标明来自哪一节，可"回到原文"或"问 AI"。
- 卡点清单：所有标记为没完全掌握的点，按书和小节分组；可以"让 AI 重讲这个点"，讲懂后划掉。

### 6.6 笔记

- 按书 → 章 → 节组织。每节一份：摘要、问答（自动整理你问过的问题和 AI 的结论）、岔路记录、卡点、高亮、你自己写的。
- 导出 Markdown：每节一个文件，目录结构和 `aima4e-markdown/课程讲义/` 一致。导出 Anki CSV：闪卡。
- 导出时默认去掉大段原文引用（超过 2 句的原文只保留页码和第一句），方便分享笔记；导出选项里可以改成保留全文。

### 6.7 AI 服务

- 和 AShareSim 一样：支持 OpenAI Responses 和 Anthropic Messages 两种协议，可配置多个服务（名称、协议、Base URL、API Key、模型），能测试连接。Key 存 Android Keystore，不写进日志和导出文件。
- 讲解模型和整理模型分开选：讲解用强一点的模型，摘要、闪卡草稿用便宜的模型。
- 固定部分（讲解规则 + 书的地图）走 prompt caching，同一本书反复对话很省。
- 显示每本书累计用了多少 token，方便估算费用。

### 6.8 语音（M5）

接入的模型只输出文字，语音不靠模型，靠手机系统自带的语音识别和朗读引擎，不需要额外的 Key：

- **语音提问**：按住麦克风说话 → Android `SpeechRecognizer` 转成文字 → 按普通提问处理，发送前可以改。设备没有可用的识别服务时（部分没有 Google 服务的国产机），不显示麦克风按钮。
- **朗读讲解**：用 Android `TextToSpeech` 朗读。讲解里的公式、引用标记、代码不能直接念，所以朗读前先把讲解转成"朗读稿"：
  - 去掉引用标记和 Markdown 符号；
  - 简单公式按规则转成读法（`f(n) = g(n) + h(n)` → "f n 等于 g n 加 h n"）；
  - 复杂公式、表格、代码块念成"这里有一个公式，请看屏幕"；
  - 打开"通勤模式"后，讲解规则会要求模型在每段讲解后面多写一段口语化的朗读稿（文字模型就能写），朗读用这一段。
- **通勤模式**：自动朗读每段讲解，读完停在检查问题；可以说"继续""再讲一遍""换个说法"代替点按钮。
- 中文朗读的音色取决于手机装的 TTS 引擎。以后如果配置的服务支持语音接口（如 OpenAI 的 `audio/speech`、`audio/transcriptions`），可以在设置里换成云端音色（V2）。

### 6.9 我的

- 解析服务：MinerU Token（显示有效期，过期提醒）、默认解析模型、今日额度、上传前确认开关。
- AI 服务、讲解偏好、存储（每本书占用、清理解析缓存但保留学习记录）、备份（整库导出 / 导入）、关于。

## 7. AI 上下文与工具（概要）

每轮请求按层组装，详细规则见 [伴读引擎规格](STUDY_ENGINE.md)：

```
┌ 固定部分（缓存）  讲解规则 · 书的地图（全书目录 + 已学小节摘要）
├ 当前小节原文      主线所在小节（或当前段）的全部内容块
├ 学习记录          这本书的进度、卡点、最近问过的问题
├ 按需加载          岔路原文 / 搜索结果
└ 最近几轮对话
```

只读工具：`load_section`、`search_book`、`get_figure`、`get_notes`。
每节开始时，整理模型先根据本节原文生成路线图（2–5 步，每步绑定一段连续的内容块），见引擎规格 §4.1。
需要你确认的写操作：`propose_summary`、`propose_cards`、`mark_stuck`、`advance_progress`。

一本几百页的书，"目录 + 摘要 + 按需加载整节原文"就足够准确，比向量检索简单，也不会把原文切得七零八落。

## 8. 视觉

- 浅色为主，支持深色。整体像一本书：正文区暖白纸色，书中原文用宋体，界面和讲解用黑体。
- 主色墨蓝（伴读、主线），岔路用紫色，高亮用浅黄，卡点用橙色。
- 视觉方向在重做中（见 `PRODUCT.md`、`DESIGN.md`），本节的配色和字体以 DESIGN.md 为准。
- 讲解正文字号 16，行高 1.75；读书模式字号可调。
- 页面只常驻展示内容、操作和当前状态；token、费用等补充信息按需展开。

## 9. 技术方案（概要）

| 层 | 选择 |
| --- | --- |
| App | React Native 0.87 + TypeScript，Android 先行。和 AShareSim 同栈，直接复用它的 AI 协议层、流式对话、Keychain、对话排版 |
| 状态 | zustand |
| 存储 | op-sqlite：`book`、`book_file`（SHA-256、分片）、`block`（MinerU 内容块：类型、页码、位置框、文本、图片路径）、`block_fts`（FTS5 全文搜索）、`section`（地图）、`study_state`（主线指针、岔路栈）、`message`、`section_note`、`card`、`review_log`、`highlight`、`ai_service` |
| PDF 渲染 | Android PdfRenderer（原版页）+ 位置框叠加层（高亮、讲过的段落） |
| 重排渲染 | 本地 WebView + 离线打包的 KaTeX 渲染 Markdown，不联网 |
| EPUB | 本地解压，解析 OPF / nav 目录 |
| 解析 | MinerU 官方精准解析 API（申请上传地址 → 上传 → 轮询 → 下载结果包）；Token 存 Keystore |
| 伴读引擎 | 纯 TypeScript、无 UI 依赖：地图构建、上下文组装、岔路状态机、引用校验、复习调度；Jest 单元测试，用 aima4e 第 3 章的真实解析结果做测试用例 |
| CI | 沿用 AShareSim 的 GitHub Actions：lint + tsc + jest、Android debug APK |

没有后端。书只在两种情况下离开手机：上传给 MinerU 解析（你确认后），以及当前讲解需要的小节原文发给你配置的 AI 服务。
