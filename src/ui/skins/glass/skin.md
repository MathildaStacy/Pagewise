# 苹果风组件覆盖

遵循 `docs/dev/02-skins.md` 的同一功能、区域和文案契约，以 `docs/design/explore/src/apple.html` 为视觉参考。

| 覆盖                    | 与纸感的结构差异                                                                    |
| ----------------------- | ----------------------------------------------------------------------------------- |
| AppBar                  | 根页使用随滚动收起的大标题；push 页居中标题与带上页名称的返回键，滚动后出现材质背景 |
| TabBar                  | 安全区上方悬浮胶囊，选中项有胶囊底，不使用通栏顶分隔线                              |
| ModeSwitch / Segmented  | 灰色胶囊轨道与可滑动的浅色滑块；减少动态效果时直接定位                              |
| Switch                  | 保留原生开关与无障碍语义，打开态使用绿色                                            |
| Button                  | 全胶囊、按下缩放与填充反馈；操作与文案保持原样                                      |
| ListSection / Row       | inset 圆角分组，行分隔线缩进，容器随文字增高                                        |
| StepProgress            | 横向胶囊步骤轨道，完成有勾、跳过有删除线，逐步可点                                  |
| QuickActions / Composer | 横向材质 chips 与悬浮胶囊输入框；发送、停止、引用操作沿用同一契约                   |
| Sheet                   | 左右下留白、40dp 圆角和材质背景；动作竖排，主动作在前                               |
| Dialog                  | 居中 iOS alert，按钮由细线分隔，长文字可滚动                                        |
| Toast                   | 顶部材质 HUD 胶囊与语义图标                                                         |
| SelectionMenu           | 浅色材质编辑菜单，项目由细线分隔，按锚点避开屏幕边缘                                |
| Glass                   | 独立背景 BlurView；关闭模糊或平台不支持时保留 Token 半透明填充                      |

Sheet 在 paper 与 glass 中使用同一个函数引用。内部只切换布局和背景层，正文 children 的 React 层级固定；切换皮肤和深浅色不会重建输入表单或关闭浮层。组件内部不持有业务状态。

V1 没有整页替换，也没有新增 L3 插槽；`ShelfContinueCard`、`ReviewHero` 继续沿用基础结构。听讲区为悬浮输入预留空间由页面布局处理，皮肤不会改变导航或进度规则。

所有交互目标至少 48dp；文字默认跟随系统字号，不用固定行高容器或 `numberOfLines` 截断操作文案。低端设备与省电状态由 Provider 的 `blurEnabled` 开关传入，原生硬件检测在后续平台能力具备后接入。
